# かせぐんぼ SNS 運用

「かせぐんぼ」（隠れる側のかくれんぼ × インクリメンタル）を世に出すための作業場所。
Claude が文案・予定・素材のリストを作り、**投稿・アカウント操作はすべて開発者本人が行う**。

## 発信先

| 場所 | 役割 | 状態 |
|---|---|---|
| X（ゲーム専用アカウント） | 開発の様子を毎日少しずつ見せる。ファンを作る | アカウント未作成 → [profile.md](profile.md) |
| itch.io | 遊べる場所（体験版を置く）。X の投稿の行き先 | ページ未作成 → [store-pages.md](store-pages.md) |
| Steam | ウィッシュリストを集める場所（Steamworks 登録・費用 $100 が要る） | 未定。後で決める |

## 流れ

```
Claude: drafts/ に下書き（文・画像の指定・投稿日時）
   ↓
あなた: 読んで OK / 直してほしい所をチャットで言う
   ↓
あなた: X に投稿（コピペ＋画像を付ける）
   ↓
Claude: posted/log.md に記録（日時・URL・あとで反応の数）→ 次の下書きに生かす
```

- 画像・GIF は [shotlist.md](shotlist.md) にある物をあなたが撮って `media/` に入れる（Claude は場面とファイル名を指定する）
- 下書きのファイル名：`drafts/<番号>_<短い名前>.md`（番号は投稿する順）。投稿したら `posted/` へ移し、`posted/log.md` に URL を書く
- 本文は X の上限（280。日本語・絵文字は 1 字 = 2）に収める
- 予定は [calendar.md](calendar.md)、口調・ハッシュタグ・やらないことは [voice.md](voice.md)

## フォルダ

| パス | 中身 |
|---|---|
| `profile.md` | X アカウントの名前・ID 候補・自己紹介・ヘッダー画像の案 |
| `store-pages.md` | itch.io / Steam のページの文 |
| `voice.md` | 口調・投稿の柱・ハッシュタグ・NG |
| `calendar.md` | 投稿予定 |
| `shotlist.md` | 撮ってほしいスクリーンショット・GIF |
| `drafts/` | 投稿前の下書き |
| `posted/` | 投稿済み（`log.md` に記録） |
| `media/` | 投稿に使う画像・GIF |

## 決まっていないこと

- 発売・体験版の予定（いつ・どこで・無料か有料か）→ 決まったら投稿の「行き先」が作れる
- 開発者名を出すか（個人名 / サークル名 / 名無し）
- 英語でも投稿するか（海外のインディー好きに届く。最初は日本語だけで始める案）
