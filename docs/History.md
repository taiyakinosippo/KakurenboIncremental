# これまでの経緯（Claude との会話のまとめ）

別のパソコンの Claude が続きから作業できるよう、ユーザーの依頼と決めたことを時系列でまとめたもの。
仕様の正本は [GameDesign.md](GameDesign.md)、作業ルールは [CLAUDE.md](../CLAUDE.md)。
会話そのもの（全文）はユーザーが書き出した zip（session-export-*.zip）にあるが、大きいので普段はこのファイルを読む。

## ユーザーについて

- UE は初心者。アルゴリズムと C# は得意。エディタは VSCode
- 役割分担: Claude が C++・CSV・ini・設計書・ビルド・テスト・push、ユーザーがエディタ作業（BP・メッシュ・UI の見た目）とプレイテスト
- push は自動でしてよい（「プッシュなど自動でして大丈夫です」）
- ユーザーの UE エディタのプロセスは勝手に終了しない。ビルドで DLL がロックされたら閉じてもらう
- 自動テストはユーザーのセーブを読み書きしない（-KakuNoSave・専用スロット）

## 依頼と決めたこと（古い順）

1. **最初の構想**: 隠れる側になって鬼から逃げる。コインは隠れた時間と連打で稼ぐ。制限時間まで隠れれば大きな報酬と次のステージ。
   最初は何もない空間で連打するだけ。コインで壁などを買って隠れやすくする。連打は音が出て鬼が寄ってくる。
   購入・設置・かくれんぼのパートに分かれる。インフレさせるのは壁・連打コイン・時間コイン・罠。3D で高低差あり
2. **壁**: 耐久があり壊れる。鬼は範囲攻撃で基本一撃 → 高い壁を買う必要がある。壊れた壁は買い直し。
   見つかってもペナルティなし（そのままリザルト）。配置はグリッド
3. **M1〜M3 を連続で作成**（最小ループ・鬼・購入と設置）
4. **視点**: 視点が動かせず空間が分からない → 設置は俯瞰、プレイ中は 3D の中にいる視点に
5. **クリックで画面が拡縮される不具合を修正**、鬼がぶつかったら見つかるように
6. **大きな変更**:
   - 視線で見つけるのはなし（触れたらアウト。見られたら追いかけられるだけ）
   - かくれんぼ中もプレイヤーが動ける。お宝を毎回ランダムな位置に出す
   - 鬼は音を聞いた・見つけたとき、一定時間か見失ったらうろうろに戻る
   - ブロック 1 段 = プレイヤーの背の高さ（160cm）
   - 置いたブロックは保存し、壊されたら在庫から自動修復
   - 鬼を 2 体に
   - 全部壁で囲むと何も見えなくなるので **三人称視点**（「二人称」は言い間違い）
7. **鬼の速さをプレイヤーの約 2 倍**に。M4（CSV のバランスデータ・セーブとロード）
8. **鬼の改修**:
   - 鬼は入り口から入る。目の前に壁があり、他に道が無いときだけ壊す
   - 角に斜めに置いた壁のような「中が空洞」の場所は壊して調べる
   - パックマンのように 4 種類: スピード（大雑把に全体・速い・壊す力弱い・積極的）、
     パワー（見つけた壁を壊す・力強い・遅い・消極的）、慎重（速い・隅々まで調べる・同じ種類で情報共有・壁は 1 個ずつ）、標準
   - ジャンプすると鬼がくるくる回る不具合を修正
   - **M5（罠・演出・バランス調整）も同時に**
9. **別のパソコンでも開発したい** → [Setup.md](Setup.md)、UE の場所を自動で探すように。会話の履歴も持っていきたい → このファイル
10. **M6（2026-10-06）**:
    - **消音壁**：周囲を囲まれている場合のみ音を小さくする
    - **壁の補強をやめる**。代わりに**転生**を入れ、転生で壁を硬くしていく
    - プレイヤーのジャンプ → 一度「無しに」と言われたが、**「やっぱりそのまま」**（ジャンプは残す）
    - **鬼が必ずここから出てくるとわかる入り口**を作る
    - **購入パートで壊れた壁・使った罠の個数**を知りたい
    - **設置パートは上から俯瞰**、そのときプレイヤーは**非表示**
    - 逃げる用の**ダッシュ**：一定時間加速する代わりに大きな音、クールタイムあり
    - 鬼の見た目を Fab の「Cute Creature」（https://www.fab.com/listings/c599865a-8535-40d1-b37f-67c9084a6042 ・無料）に変えたい
    - バグ報告：鬼どうしが違う方向へ行こうとすると押し合って動かなくなる → 鬼どうしは体がすり抜けるように修正
11. **M7（2026-10-06）**:
    - ユーザーが Cute Creature をプロジェクトに追加（Git から取ったプロジェクトはランチャーの一覧に出ないので、エディタの Fab から追加）
    - **転生ポイントは使うもの**に：ステージ−4 のポイントで**永続強化**を買う。壁の硬さ・お宝の強化・ダッシュのクールタイムと速度・ジャンプ。
      **ダッシュとジャンプはデフォルトでは無し**、強化で得られる
    - **購入パートと設置パートの UI をマウスで選べるように**
    - **鬼の色を種類ごとに別の色に**（Cute Creature の色違いマテリアル）
12. **M8（2026-10-06）**:
    - バグ報告：門の前を壁で囲むと、鬼が壁を壊さずに出てこなくなる → 囲まれた場所にいる鬼は壁を壊して外へ出るように
    - 購入パートに**壊れた壁の一括補充ボタン**（優先順位は値段が高い物から）
    - **消音壁が強すぎる** → 一定回数音を消したら壊れる。回数は永続強化で増える
    - 転生できるようになると購入パートの UI がずれる → ボタンの位置を固定
    - **壁も買うごとに値段の倍率**をかける。それに伴って罠の倍率も上げる。消音壁は例外で罠と同じ倍率
    - **スピード鬼**：おとりに強いよう「音に敏感」の特性。**パワー鬼**：トリモチで動けない時間を短く、その後のかからない間に踏んだトリモチは解除
    - **慎重鬼**：仲間が攻撃している壁とその周り（ドーナツ形の壁など）には興味を示さず、他の壁へ向かう
    - プレイテストの結論「スピードはトリモチに弱くおとりに強い／パワーはおとりに弱くトリモチに強い／慎重はたくさん置かれた壁に弱いが効率的に探しに来る」
      をもとに**レベルデザインを考え直す**（GameDesign.md の「レベルデザイン」）
    - **転生したら、まず転生のお店へ**
13. **M9（2026-10-08）**:
    - **設置パートから購入パートへ戻れる**ように
    - 慎重鬼が想定通りに動かない：**細い道があると必ず通ってくる・壁に囲まれた所を真っ先に壊しに来る・仲間が操作している所を避ける仕組みが効いていない** → 探し方を作り直し
    - **宝物鬼**：壁を壊すのも探すのも苦手だが、**お宝の周りをぐるぐる徘徊**。**クリック（連打）の音には鈍感、足音に敏感**
    - **プレイヤーの足音とジャンプの音**。**消音壁でなくても壁に囲まれている間は 80% 聞こえなくなる**。大きさは連打の 50〜80%
    - **探知鬼**：開始時にランダムな位置へ移動してそこから動かない代わりに、**見つけたらかなりの範囲の鬼を呼び寄せる**
    - **館の見た目**を Fab の「Stylized Library」（https://www.fab.com/listings/6150cf8e-8105-4da0-9209-3edbc2afb673 ）に。ユーザーが追加済み（`Content/Stylized_Library`）
    - 増えた鬼に合わせて**レベルデザインをし直し、マップを増やす**
    - **鬼・お宝の方向の矢印を消して、音でわかるように**（鬼のどたどたという足音・お宝のキラキラ）
    - **雰囲気をもっとポップで、なおかつ隠れて逃げる暗い雰囲気に**、**BGM** も
    - 「チャットへの文章の出力は最後の報告だけにして、長い間作業してほしい」

14. **M10（2026-10-08）**:
    - 設置パートで**積み重ねたのが分かりにくい → カメラを立体的に動かせるように**（Z/X・ホイールを押して上下ドラッグで傾ける。最初は今まで通り真上）
    - **ジャンプで家具などに乗ると鬼が追ってこられず無敵になる** → 台の上のプレイヤーが見えたら、そばまで来て飛び乗る（280cm まで）
    - **難易度が全体的に下がった気がする → 標準鬼を少しだけ増やす**（ステージ 3・6・8・10 に 1 体ずつ。1 ステージ最大 6 体は守る）
    - 「使用量を節約するため、最後に確認用の文章だけを表示して」

15. **M11（2026-10-08）**:
    - 「**ダッシュいらない**ですね。ジャンルが**インクリメンタルかくれんぼストラテジー**なので。ダッシュにプラスして**煙幕を投げる**のは？
      **ダッシュのクールタイムを回数に変更**する感じで」
      → 解釈：反射神経で使うクールタイム制のダッシュはやめ、**煙幕を投げて走る「回数制の逃げる道具」（煙幕ダッシュ）**にした。
      1 ラウンドに 1 回、転生のお店「煙幕の数」で最大 4 回。煙（半径 2.6m・7 秒）の中・向こう側は鬼から見えない。音は今まで通り大きい
    - 転生のお店：「ダッシュの速さ」→「煙幕ダッシュ」（解放）、「ダッシュの回復」→「煙幕の数」（同じ並びの場所なので、セーブのレベルはそのまま引き継ぐ）
    - 「**速さを煙幕の持続時間にして、最小 1 秒最大 7 秒で**」→ 「煙幕ダッシュ」の強化は走る速さではなく煙が残る時間（Lv1〜4 で 1, 3, 5, 7 秒）。走る速さは ×1.4 で固定

16. **M12（2026-10-08）**:
    - 「**より音でわかるゲーム性に**。左右で音が聞こえる大きさが違ったり、画面を見なくても何か来ているのが分かるように。見つかっていないときの足音が小さすぎる。宝石も」
      → 自前の左右の聞こえ方（大きさの差・時間差・後ろと壁の向こうはこもる）、鬼の足音とお宝を大きく遠くまで、鬼が気づいた「ン？」、見つかった「！」をその鬼の場所から、心臓の音
    - 「**お宝鬼はもともとお宝があった場所にも徘徊する**ように」
    - 「ステージごとに 3 回同じマップを使っている → **全部違うマップ、違う大きさ**に。**最初はデフォルトで物が多めでどんどん少なく、大きさはどんどん大きく**」
    - 「**壁とか床も送った見た目に**。**壁をちゃんと高くして外の世界が見えないように**」。Fab：プレイヤーの見た目（Cartoon Male Character Rigged 002）、
      石と木の壁（Substance Materials Vol 01 - Wood）、鉄の壁（Stylized Metallic Floor）、宝石（Diamond Gem Shape Set - 2）。ユーザーが追加済み（FBX は Content に展開されていた）
    - 「作るにあたってデザインで足りないものがあれば教えて」
    - 途中で追加：「**後半は煙幕ある前提のステージ設計でいい**、インクリメンタルらしく、**転生しないときついポイントを用意して自然に転生してもらう**。それに伴い**ステージ数を増やして**」    - M12 の後：「**自動ビルドプログラムを作成しておいて**」→ Tools/AutoBuild（pull → ビルド → 取り込み・-Test・-Package・-Watch・git pull 後の自動ビルドのフック）
    - 「石の見た目」：Fab「Stylized Hand-Painted Stone Wall」（ユーザーが追加済み）→ 石の壁・地下室と迷いの間の壁に
    - 「**パッケージまでするようにして**」→ AutoBuild の最後に配布用の .exe を作る（変わっていなければ飛ばす。-NoPackage でしない）
    - 「**アニメーションは公式のもの使って**」→ UE 公式のマネキンのアニメーション（テンプレートからコピー）で、見えないマネキンの骨の回転をプレイヤーのモデルへ写す
    - 「足音の重厚感はいいが、**距離に関係なく大きく聞こえて**どのくらい離れているかわからない」「**宝石も**距離による増減を大きく」→ 距離が 2 倍で約 -7.5dB・遠いほどこもる・近くの音を頭打ちにしない
    - 「**クリックの音の範囲が広すぎる**」→ 連打の音が届く距離 ×0.75
    - 「**足音を小さくするときはしゃがむ**ことで、体の半分くらいの物にも隠れられるように」→ しのび足でしゃがむ（70cm）
    - 「**Object がマスの間**にあるとブロックが置けない → マスに合わせて置く」→ 家具のメッシュをマスちょうどに収める
    - 「**床の色と置いた木の壁の色が似ている**」→ 置く木の壁を明るい色に塗った板に
    - 「家具が**マスの間**にあって壁が置けない」（スクリーンショット付き）→ 家具のメッシュがマスからはみ出さないことをテストで確かめるように
    - 「設置パートで**すべてのオブジェクトをリセットするボタン**」→ 全部回収（ボタン・Delete。2 回押す）
    - 「**壁の上に乗って**アスレチックで逃げられる。**完全に壁にして隣の部屋が見えないように**」→ 部屋の壁を外周と同じ 10m に
    - 「**宝物鬼は目標の宝へ最短経路を塞いでいる壁を壊して進む**」
    - 「**ツボにしゃがみながら歩くとがくがく**」→ カメラが家具をすり抜けるように・しゃがんだ姿勢の高さをなめらかに
    - 「**連打のメリットを大きく**するため時間収入を減らす。**時間だけだとクリア時点で収支がちょっとプラス**くらいに」→ 時間収入 0.4 × 1.4^Lv（強化の値段 ×1.8）。リザルトに収入の内訳を出す
    - 「**マップのサイズをレベルが上がるごとに大きく**」→ 25 ステージ・ステージごとに縦横 1 マスずつ（16〜40）
    - 「消音壁」：Fab「Stucco Wall」（ユーザーが Content に画像を置いた）
    - 「**git をプライベートに変えたのでアセットも git に**。送れないものは docs に」→ docs/Assets.md。木の元のパック（2.8GB）だけは 1K に縮めたコピーを入れた
    - 「床の色と置いた木の壁の色が似ている」→ 木の壁は色を抜いて青みがかった灰色に塗った板に（前の「明るい板」でも見分けにくかった）

17. **M13（2026-10-12）操作がわかる UI/UX**：
    - 「**UI を UX に**。操作が直感的ではなく、こんな操作もあったんだ！ってなる」→ できる操作をその場で見せる：キーの形（キーキャップ）の案内、
      はじめての場面だけ出るヒント、F1 の操作説明、設置パートのカーソルの下に「置く / 回収」、ボタンにキーを添える、右上にメニュー・操作説明のボタン
    - 「**タイトルシーン**。はじめからとつづきから」→ 起動したらタイトル（つづきから / はじめから / 設定 / やめる）。はじめからはセーブを消すので確かめる
    - 「**設定画面**」「**オプション（音量・マウス感度・キーコンフィグ）**」→ 設定画面（全体・BGM・効果音・マウス感度・上下反転・ヒント・画面）とキー設定。Esc の一時停止メニューから
    - 「**ゲーム中のテキストを消すか、雰囲気に合うものに**」→ 長い説明はヒント・操作説明へ。「もういいかい…」「鬼が来る…」「みーつけた」、鬼の様子はひとこと
    - 「**敵の目が赤く光っていると雰囲気が出る。追いかけてくるとき全員それに**」→ 追いかけてくる鬼は種類に関係なく目が赤く光る（Cute Creature のマテリアルの Emissive_power）
    - 「**ダッシュの煙がたまに出ない**」→ カメラとプレイヤーの間の煙を隠していたため、前へ走ると煙が見えなかった。半透明の煙にして隠さないように
    - 「**しゃがみながら地球儀とかに歩くとがくがく**」→ しゃがむ高さを歩く姿勢から毎フレーム測っていたのをやめ、一定に（CrouchWalk テストで揺れ 0 を確認）
    - 「**マス目の真ん中に配置されて 2 ブロック分のスペースを取っているオブジェクト**」→ 2×2 などの家具は、マスごとに 1 個ずつ置く
    - 「**転生回数ごとに初期コイン数を +**。アップグレードではなく自動で」→ 転生後のコイン = 転生回数 × 500（Prestige.csv の StartCoinsPerPrestige）

18. **M14（2026-10-12）考えて隠れる・本物の館・コントローラー**：
    - 「**かくれんぼインクリメンタルのコンセプトを満たしているか**。ジャンプで逃げるアクションになっている」→ 相談して決めたこと：
      - 試行錯誤してほしいのは「**鬼をうまく引きつけたうえで見つからない壁の置き方**」。面白さは「見つかるかもしれない中で連打する緊張感」と「鬼をほんろうできたときのしてやったり感」
      - **ジャンプをやめて「よじ登る」**：1 段ずつ・時間がかかる・横に飛ばない。壁の上を歩けるのはつながっている所だけ
      - 家具の数はあまり変えず（館どうしでそろえる）、**転生してほしいステージは気持ち少なめ**。「数ではなく、考えて配置することで見つからないように」
      - 中に入れる家具は**却下**（中に入って周りを壁で囲う遊び方になるため）
      - **転生の「壁の硬さ」は倍率（掛け算）、コインの「壁の補強」は実数値（足し算）**（ユーザーの案）
    - 「**壁の種類を通常壁・消音壁・クライミング壁に**。クライミング壁は上るスピードが速い」→ 木・石・鉄はやめて 3 種類。クライミング壁は 0.3 秒で登れるが、鬼は上に飛び乗れず下から壊す（Claude の判断。階段のように使えないように）
    - 「**もっと本物の館っぽく**。今はものが雑多に置かれている一室みたい。必要なら自由にアセットストアから」→ 玄関ホール・廊下・役割のある部屋（Tools/GenerateMansion.py）、
      ユーザーが入れた Fab のパック（Medieval Room Kit・Stylized House Interior・Isometric Interiors）から手描き風でそろう物を選んで使う（カタログを撮って選んだ）。壁紙・腰壁・窓・絵・松明・床の種類
    - 「**敵の数とかをレベルに合わせて**」→ 部屋の数に合わせて見直した（1 体あたり 3〜6 部屋。門のマスが 6 つなので最大 6 体のまま）
    - 「**コントローラーの適応も**」→ XInput のゲームパッドで全部の画面を操作できるように（最後にさわった方で切り替わる・ボタンの形の案内）
    - プレイして：
      - 「**カメラがグワングワンする**」→ 部屋の壁に当たったカメラが、毎フレーム縮んだり戻ったりしていた。**縮むときはすぐ・戻るときはゆっくり**に（具体的なやり方は GameDesign.md の「カメラの揺れの直し方」）
      - 「**扉がインゲーム中だと上に何もなく、そこにあるだけに見える**」→ 出入り口の上に、枠のてっぺんから天井までの壁を付けた（かくれんぼ中だけ。当たり判定はカメラだけ）
