# これまでの経緯（Claude との会話のまとめ）

別のパソコンの Claude が続きから作業できるよう、ユーザーの依頼と決めたことを時系列でまとめたもの。
仕様の正本は [GameDesign.md](GameDesign.md)、作業ルールは [CLAUDE.md](../CLAUDE.md)。
会話そのもの（全文）はユーザーが書き出した zip（session-export-*.zip）にあるが、大きいので普段はこのファイルを読む。

## ユーザーについて

- UE は初心者。アルゴリズムと C# は得意。エディタは VSCode
- 役割分担: Claude が C++・CSV・ini・設計書・ビルド・テスト・push、ユーザーがエディタ作業（BP・メッシュ・UI の見た目）とプレイテスト
- push は自動でしてよい（「プッシュなど自動でして大丈夫です」）
- ユーザーの UE エディタのプロセスは勝手に終了しない。ビルドで DLL がロックされたら閉じてもらう
- 自動テストはユーザーのセーブを読み書きしない（-KakuNoSave・専用スロット）

## 依頼と決めたこと（古い順）

1. **最初の構想**: 隠れる側になって鬼から逃げる。コインは隠れた時間と連打で稼ぐ。制限時間まで隠れれば大きな報酬と次のステージ。
   最初は何もない空間で連打するだけ。コインで壁などを買って隠れやすくする。連打は音が出て鬼が寄ってくる。
   購入・設置・かくれんぼのパートに分かれる。インフレさせるのは壁・連打コイン・時間コイン・罠。3D で高低差あり
2. **壁**: 耐久があり壊れる。鬼は範囲攻撃で基本一撃 → 高い壁を買う必要がある。壊れた壁は買い直し。
   見つかってもペナルティなし（そのままリザルト）。配置はグリッド
3. **M1〜M3 を連続で作成**（最小ループ・鬼・購入と設置）
4. **視点**: 視点が動かせず空間が分からない → 設置は俯瞰、プレイ中は 3D の中にいる視点に
5. **クリックで画面が拡縮される不具合を修正**、鬼がぶつかったら見つかるように
6. **大きな変更**:
   - 視線で見つけるのはなし（触れたらアウト。見られたら追いかけられるだけ）
   - かくれんぼ中もプレイヤーが動ける。お宝を毎回ランダムな位置に出す
   - 鬼は音を聞いた・見つけたとき、一定時間か見失ったらうろうろに戻る
   - ブロック 1 段 = プレイヤーの背の高さ（160cm）
   - 置いたブロックは保存し、壊されたら在庫から自動修復
   - 鬼を 2 体に
   - 全部壁で囲むと何も見えなくなるので **三人称視点**（「二人称」は言い間違い）
7. **鬼の速さをプレイヤーの約 2 倍**に。M4（CSV のバランスデータ・セーブとロード）
8. **鬼の改修**:
   - 鬼は入り口から入る。目の前に壁があり、他に道が無いときだけ壊す
   - 角に斜めに置いた壁のような「中が空洞」の場所は壊して調べる
   - パックマンのように 4 種類: スピード（大雑把に全体・速い・壊す力弱い・積極的）、
     パワー（見つけた壁を壊す・力強い・遅い・消極的）、慎重（速い・隅々まで調べる・同じ種類で情報共有・壁は 1 個ずつ）、標準
   - ジャンプすると鬼がくるくる回る不具合を修正
   - **M5（罠・演出・バランス調整）も同時に**
9. **別のパソコンでも開発したい** → [Setup.md](Setup.md)、UE の場所を自動で探すように。会話の履歴も持っていきたい → このファイル
10. **M6（2026-10-06）**:
    - **消音壁**：周囲を囲まれている場合のみ音を小さくする
    - **壁の補強をやめる**。代わりに**転生**を入れ、転生で壁を硬くしていく
    - プレイヤーのジャンプ → 一度「無しに」と言われたが、**「やっぱりそのまま」**（ジャンプは残す）
    - **鬼が必ずここから出てくるとわかる入り口**を作る
    - **購入パートで壊れた壁・使った罠の個数**を知りたい
    - **設置パートは上から俯瞰**、そのときプレイヤーは**非表示**
    - 逃げる用の**ダッシュ**：一定時間加速する代わりに大きな音、クールタイムあり
    - 鬼の見た目を Fab の「Cute Creature」（https://www.fab.com/listings/c599865a-8535-40d1-b37f-67c9084a6042 ・無料）に変えたい
    - バグ報告：鬼どうしが違う方向へ行こうとすると押し合って動かなくなる → 鬼どうしは体がすり抜けるように修正
11. **M7（2026-10-06）**:
    - ユーザーが Cute Creature をプロジェクトに追加（Git から取ったプロジェクトはランチャーの一覧に出ないので、エディタの Fab から追加）
    - **転生ポイントは使うもの**に：ステージ−4 のポイントで**永続強化**を買う。壁の硬さ・お宝の強化・ダッシュのクールタイムと速度・ジャンプ。
      **ダッシュとジャンプはデフォルトでは無し**、強化で得られる
    - **購入パートと設置パートの UI をマウスで選べるように**
    - **鬼の色を種類ごとに別の色に**（Cute Creature の色違いマテリアル）
12. **M8（2026-10-06）**:
    - バグ報告：門の前を壁で囲むと、鬼が壁を壊さずに出てこなくなる → 囲まれた場所にいる鬼は壁を壊して外へ出るように
    - 購入パートに**壊れた壁の一括補充ボタン**（優先順位は値段が高い物から）
    - **消音壁が強すぎる** → 一定回数音を消したら壊れる。回数は永続強化で増える
    - 転生できるようになると購入パートの UI がずれる → ボタンの位置を固定
    - **壁も買うごとに値段の倍率**をかける。それに伴って罠の倍率も上げる。消音壁は例外で罠と同じ倍率
    - **スピード鬼**：おとりに強いよう「音に敏感」の特性。**パワー鬼**：トリモチで動けない時間を短く、その後のかからない間に踏んだトリモチは解除
    - **慎重鬼**：仲間が攻撃している壁とその周り（ドーナツ形の壁など）には興味を示さず、他の壁へ向かう
    - プレイテストの結論「スピードはトリモチに弱くおとりに強い／パワーはおとりに弱くトリモチに強い／慎重はたくさん置かれた壁に弱いが効率的に探しに来る」
      をもとに**レベルデザインを考え直す**（GameDesign.md の「レベルデザイン」）
    - **転生したら、まず転生のお店へ**
13. **M9（2026-10-08）**:
    - **設置パートから購入パートへ戻れる**ように
    - 慎重鬼が想定通りに動かない：**細い道があると必ず通ってくる・壁に囲まれた所を真っ先に壊しに来る・仲間が操作している所を避ける仕組みが効いていない** → 探し方を作り直し
    - **宝物鬼**：壁を壊すのも探すのも苦手だが、**お宝の周りをぐるぐる徘徊**。**クリック（連打）の音には鈍感、足音に敏感**
    - **プレイヤーの足音とジャンプの音**。**消音壁でなくても壁に囲まれている間は 80% 聞こえなくなる**。大きさは連打の 50〜80%
    - **探知鬼**：開始時にランダムな位置へ移動してそこから動かない代わりに、**見つけたらかなりの範囲の鬼を呼び寄せる**
    - **館の見た目**を Fab の「Stylized Library」（https://www.fab.com/listings/6150cf8e-8105-4da0-9209-3edbc2afb673 ）に。ユーザーが追加済み（`Content/Stylized_Library`）
    - 増えた鬼に合わせて**レベルデザインをし直し、マップを増やす**
    - **鬼・お宝の方向の矢印を消して、音でわかるように**（鬼のどたどたという足音・お宝のキラキラ）
    - **雰囲気をもっとポップで、なおかつ隠れて逃げる暗い雰囲気に**、**BGM** も
    - 「チャットへの文章の出力は最後の報告だけにして、長い間作業してほしい」

14. **M10（2026-10-08）**:
    - 設置パートで**積み重ねたのが分かりにくい → カメラを立体的に動かせるように**（Z/X・ホイールを押して上下ドラッグで傾ける。最初は今まで通り真上）
    - **ジャンプで家具などに乗ると鬼が追ってこられず無敵になる** → 台の上のプレイヤーが見えたら、そばまで来て飛び乗る（280cm まで）
    - **難易度が全体的に下がった気がする → 標準鬼を少しだけ増やす**（ステージ 3・6・8・10 に 1 体ずつ。1 ステージ最大 6 体は守る）
    - 「使用量を節約するため、最後に確認用の文章だけを表示して」

## Claude の判断で決めたこと（ユーザーに報告済み・変更の希望は未回答）

- パワー鬼は音を気にしない（おとりが効かない）
- 罠で動けない鬼は触れても捕まえられない。抜け出した後 3 秒は罠にかからない
- 罠の値段は持っている数が増えるほど上がる（置きすぎ防止）
- ~~購入パートに「壁の補強」を追加~~ → M6 でユーザーの依頼により削除（転生に置き換え）
- 鬼の種類はステージ 1〜4 で 1 つずつ登場させる（ステージ 1 は標準鬼 2 体）
- 効果音・演出は仮でプログラムで作った（音アセットは GameMode の SoundOverrides で差し替え）
- M6 の細かい仕様（ユーザーに報告済み・希望があれば変える）:
  - 転生はステージ 5 から、購入パートで P を 2 回。転生ポイント = ステージ − 4、壁の耐久 ×1.5^ポイント。
    コイン・ステージ・強化・在庫・置いた壁と罠はリセット、**設計図は残す**（買い直せば自動で直る）
  - 消音壁：耐久 3・300 コイン・NoiseDamping 0.8。空洞を囲む壁の平均で効く（全部消音壁なら音 −80%）。おとりの音には効かない
  - 鬼の出入り口：東側（+X）の外周の真ん中に赤い鳥居形の門。前の 3×2 マスから 1 体ずつ出る。そこには壁・罠・スタート位置を置けない
  - 設置パート：真上（ピッチ −90）・舞台全体が入る高さ。WASD はカメラを動かす。スタート位置は青い印、T でカーソルのマスへ
  - ダッシュ：Shift、1.5 秒 ×1.8、音は連打の 1.5 倍の距離、クールタイム 6 秒
  - 鬼の見た目：アセットはユーザーの Fab アカウントで追加する必要があるので、DefaultGame.ini にパスを書けば差し替わる仕組みだけ作った
- M7 の細かい仕様（ユーザーに報告済み・希望があれば変える）:
  - **リポジトリが公開（public）なので、Fab のアセット（Content/CuteCreature）は Git に入れない**（ライセンス上、再配布になる）。
    別のパソコンでもエディタの Fab から追加する。無ければ円柱で動く
  - Cute Creature にはアニメーション BP が無いので、C++ で状態に合わせて直接再生（待機・走る・攻撃・見つけた=Win・罠=Lose）。
    大きさは体の高さ 190cm に自動で合わせる。色：標準=黒・スピード=青・パワー=橙・慎重=ピンク。包帯（SK_Bandage）も重ねる
  - 転生のお店の価格と効果は Data/PrestigeUpgrades.csv（GameDesign.md の表）。ダッシュは「ダッシュの速さ」Lv1 で解放、クールタイムの基本は 8 秒に
  - 転生しても「転生のお店の強化」は残る。版 3 のセーブの転生ポイントは「使えるポイント」として引き継ぐ
  - 購入パートはカーソルを出す（マウスの左右でカメラを回すのは、リザルトだけにした）
- M8 の細かい仕様（ユーザーに報告済み・希望があれば変える）:
  - 「音に敏感」＝プレイヤーの音が 1.5 倍の距離まで聞こえ、おとりはにせものとわかって寄っていかない（スピード鬼）
  - パワー鬼は連打は気にしないが、おとりには 1.6 倍の距離から寄っていく（以前は音を全く気にしなかった）。トリモチは 0.4 倍の時間。スピード鬼はトリモチ 1.5 倍
  - 消音壁は 40 回（連打 1・ダッシュ 3 ずつ減る）。囲んでいる消音壁が全部同時に減る。壊れたら設計図に残る
  - まとめて補充は壁だけでなく使った罠も対象（高いものから・買えるだけ）。R キーでも
  - 壁の値段の倍率：木 1.04・石 1.06・鉄 1.08・消音 1.5。罠：トリモチ 1.3→1.5・おとり 1.35→1.6
  - ステージ表を並べ直した（ステージ 1 は標準鬼 1 体、3 でスピード、4 でパワー、5 で慎重 2 体、6 でスピード＋パワー…）
  - 慎重鬼の「建物」＝斜めも含めてつながった壁と、それに接する空洞。仲間が調べに行く・壊している建物には行かない
- M9 の細かい仕様（ユーザーに報告済み・希望があれば変える）:
  - 館のマップは 5 つ（大広間・書庫・客間・物置・回廊）。**家具は壊せない障害物**（Stylized Library のメッシュ。無いパソコンでは箱）。3 ステージごとにマップが変わり、
    **変わるときは置いていた壁・罠を在庫に戻し、設計図はマップごとにとっておく**（戻ってきたら在庫から自動で直る）
  - 慎重鬼：周り 4 マスの見通せるマスを「調べた」と共有（60 秒）。慎重鬼の数で舞台を南北に分けて担当。細い道・行き止まりは後回し、うろうろ中は細い道を通らない。
    空洞（囲まれた場所）は広い場所の見残しが 12% 以下になってから。空洞は仲間が向かっている・調べている建物を避ける
  - 宝物鬼：半径 2 マスの周りを 2 周したら別のお宝へ。壁を壊す力 ×0.4、連打 ×0.3、足音 ×2.2、空洞は調べない。見た目は橙＋金の王冠（色違いのマテリアルが足りないため）
  - 探知鬼：見張りの場所はスタート位置・門・ほかの探知鬼から 6 マス以上離れたランダムな空きマス。視界 1500cm・64 度で首を回す。
    見つけたら **24m 以内の鬼**を呼ぶ（5 秒ごと）。自分は追わない。音は聞かない。紫＋赤いランプのアンテナ
  - 足音 0.5（1.2m ごと）・ジャンプ 0.7。標準・慎重鬼は足音を ×0.6、スピード ×1.0、パワー・探知は 0。囲まれていると ×0.2（消音壁は傷まない）
  - **しのび足（Ctrl / C）を追加**（頼まれてはいないが、足音を避ける手段として）。速さ半分・足音 ×0.3
  - 左上の鬼の一覧から距離を消した（音で探すため）。追いかけ始めた鬼の頭の上の「！」は残した。門の方向の矢印（開始前）も残した
  - BGM・足音・キラキラもプログラムで作った音（GameMode の SoundOverrides で効果音、MusicOverrides で BGM を音アセットに差し替えられる）
  - 自動テストは家具の無い舞台で行う（壁を置くマスが家具で塞がらないように）。マップのテストだけ本物のマップ
