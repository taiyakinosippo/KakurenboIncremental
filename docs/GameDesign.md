# かせぐんぼ 設計書

ゲームの題名は **「かせぐんぼ」**（稼ぐ＋かくれんぼ。2026-10-14 に決定）。プロジェクト名・フォルダ名・.exe の名前は KakurenboIncremental のまま。

## コンセプト

プレイヤーは**隠れる側**。鬼から逃げ切りながらコインを稼ぎ、ブロックや強化を買って
隠れ場所をインフレさせていく 3D インクリメンタルゲーム。

核となるジレンマ：**連打すれば稼げるが、音で鬼を呼び寄せる。お宝を取りに行けば稼げるが、隠れ場所から出ることになる。**

## ゲームループ

```
[タイトル] → （はじめから）[かくれんぼ] → [リザルト] → [購入] → [設置] → [かくれんぼ] → …
            （つづきから）[設置] → [かくれんぼ] → …
```

| パート | 視点 | プレイヤーの操作（初期設定のキー。設定画面のキー設定で変えられる） | 内容 |
|---|---|---|---|
| タイトル | 斜め上から館をゆっくり回る | クリック・↑↓ と Enter：**つづきから / はじめから / 設定 / やめる** | 起動したらまずここ（下の「タイトル・メニュー・設定」） |
| 購入 | 俯瞰 | **クリック**・数字キーで購入 / **［×1］［×10］［最大］でまとめ買い** / Tab・タブのクリックでお店の切り替え（コイン → 宝石 → 転生） / P を 2 回・ボタンで転生 / Enter・ボタンで次へ | 「コインのお店」で強化・壁・罠、「**宝石のお店**」でふしぎな道具（M15）、「転生のお店」で永続強化を買う。**壊れた壁・使った罠の数を種類ごとに表示**。ステージ 5 から転生できる |
| 設置 | **真上から**（Z/X で斜めに傾けられる。プレイヤーは表示しない） | WASD でカメラを動かす、カーソルでマスを指して置く・回収、**Delete・ボタンを 2 回で全部回収**、**下の欄をクリック**・数字キーで置く物を選ぶ、T でスタート位置を動かす、ボタン・Enter で開始、**ボタン・B で購入パートへ戻る** | 壁と罠をグリッドに置く・回収する。**壊れた壁・使った罠は開始時に在庫から自動で直す**。購入パートへ戻っても置いた壁・罠はそのまま |
| かくれんぼ | **三人称** | WASD で移動、**Ctrl でしゃがむ（しのび足。1 回押すと切り替え。設定で「押している間」にもできる）**、（解放したら）Space で**よじ登る**・Shift で煙幕ダッシュ（回数制）、左クリック / F で連打、**G でだるまさんがころんだ**（宝石のお店の道具）、マウスでカメラ | 時間・連打・お宝でコインを得る。開始 3 秒後に**赤い門（鬼の出入り口）から**鬼が出てくる（種類と数はステージごと）。**鬼とお宝の場所は矢印では出ない。足音とキラキラの音で見当をつける** |
| リザルト | 俯瞰 | **ボタン**・Enter で次へ、Q/E でカメラ | 獲得コイン・お宝・壊された壁・使った罠の数を表示。クリアなら次のステージへ |

どのパートでも **Esc でメニュー**（一時停止・操作説明・設定・タイトルへ）、**F1（H）で操作説明**。カーソルが出ているパートは右上のボタンでも開ける。
**コントローラー（ゲームパッド）でも全部遊べる**（M14。下の「コントローラー」）。

## タイトル・メニュー・設定（M13：操作がわかる UI/UX）

ユーザーの依頼：「操作が直感的ではなく、こんな操作もあったんだ！ってなる」→ **できる操作をその場で見せる**ことにした。

- **タイトル画面**：起動したらまずタイトル。夜の館を斜め上からゆっくり回って見せる。左上に**ロゴ「かせぐんぼ」**（「かせぐ」は小判の金色、「んぼ」は夜の月の色。ぐ の濁点は小判 2 枚、ぼ の濁点はのぞく目。ロゴの絵が無ければ文字で出す）。ウィンドウの題名も「かせぐんぼ」。メニューは **つづきから**（セーブが無いと押せない。ステージと転生回数を出す）・
  **はじめから**（セーブがあれば「セーブを消して、はじめから」を確かめる）・**設定**・**やめる**。クリックでも、↑↓（W/S）と Enter でも選べる
  - セーブがあれば起動したときに読み込んでおき、後ろにその館が見える。タイトルでは保存しない（遊ぶ前にセーブを上書きしない）
- **一時停止メニュー**（Esc・右上のボタン）：つづける / 操作説明 / 設定 / タイトルへ。かくれんぼ中は**ゲームが止まる**（鬼も時間も止まる）。
  かくれんぼの途中でタイトルへ戻ると、そのラウンドは始める前の状態に戻る（確かめてから）。ほかのパートでは保存してから戻る
- **設定画面**：全体の音量・BGM・効果音（つまみ）、マウス感度（×0.25〜×3.5）、スティック感度、マウスの上下反転、**しゃがむ（1 回押して切り替え / 押している間。M15）**、操作のヒントの表示、画面（ウィンドウ / フルスクリーン）、**コントローラーの配置（Xbox / 任天堂）**、**キー設定**。
  変えるとすぐ反映され、`Saved/SaveGames/KakurenboSettings.sav` に保存する（進み具合のセーブとは別。自動テストの -KakuNoSave では読み書きしない）
- **キー設定**：21 の操作（移動・連打・しゃがむ・煙幕・よじ登る・カメラ・次へ・設置と購入の操作・操作説明・だるまさんがころんだ）に 2 つずつキーを割り当てられる。
  欄をクリックして使いたいキーを押す（Esc で取り消し・右クリックで 2 つ目を外す）。**ほかの操作と同じキーにすると入れ替わる**（同じキーが 2 つの操作に付かない）。
  Esc・マウスのホイールと移動・~（コンソール）は使えない。画面に出るキーの案内・ヒントは、割り当てたキーで表示する
- **操作説明**（F1・H・メニュー）：今のパートでできる操作を、キーの形（キーキャップ）で一覧にする
- **画面に出す操作の案内**：文ではなく**キーの形**で「[W][A][S][D] 移動 [Ctrl] しゃがむ [左クリック] 連打」のように出す（解放していない操作は出さない）。
  設置パートはカーソルの下に「[左クリック] 置く」「[右クリック] 回収」・置けない理由を出す。ボタンにもキーを添える。設定で消せる
- **はじめての操作のヒント**：その場面に初めて来たときだけ、画面に 7 秒「ヒント」を出す（1 回見たら出ない。設定画面で「ヒントをもう一度見る」）。
  歩き方 → 連打（音で鬼が寄る）→ 鬼にさわられたら見つかる → しゃがむ → お宝の音、購入・設置のやり方、メニューと設定、
  よじ登る・煙幕ダッシュを解放したとき、はじめて追いかけられたとき（煙幕があれば煙幕を勧める）、転生できるようになったとき
- **ゲーム中の文は雰囲気に合わせて短く**（M13）：長い説明文はやめて、ヒント・操作説明へ移した
  - 開始前は「**もういいかい…**」と数字、鬼が出てきたら「鬼が来る…」、見つかったら結果画面に「**みーつけた**」、逃げ切ったら「逃げきった！」
  - 鬼の一覧はひとことで：さまよっている / 音のほうへ… / 追ってくる！ / あやしんでいる / 壁をこわしている / 動けない / 見張っている / 仲間を呼んだ！ / お宝を見まわっている
  - 残り時間は細い線と数字だけ。自分の様子（しゃがんでいる・壁の中で足音 −80%・消音壁）は左下に小さく
  - 探知鬼に見つかったら「見張りに見つかった… 鬼が〇体あつまってくる」、トリモチは「鬼がトリモチにかかった」

## コントローラー（M14）

ユーザーの依頼：「コントローラーの適応もお願いします」。XInput のゲームパッド（Xbox のコントローラーなど。PlayStation のコントローラーは Steam などで XInput にすれば使える）。

- **キーボード・マウスとコントローラーは、最後にさわった方に自動で切り替わる**（画面のキーの案内も [A] [RT] のようにボタンの形になる。Xbox の配置では A/B/X/Y は色付き）
- かくれんぼ：左スティック（十字キー）で移動・右スティックでカメラ（感度は設定の「スティック感度」×0.3〜×2.5）、RT 連打、LT しゃがむ、RB 煙幕ダッシュ、**A よじ登る**、**Y だるまさんがころんだ**、START メニュー、BACK 操作説明
- メニュー・タイトル・購入パート：十字キー・左スティックでボタンを選ぶ（金色の枠）、A で決める、B で戻る、つまみは左右で ±5%。LB / RB でお店の切り替え（次 / 前）、X まとめて補充。まとめ買いの数は上のボタンを選んで A
- 設置パート：左スティック・十字キーでカーソル（マス）を動かす（カメラが付いてくる）、A 置く（一方通行ののれんの上なら向きを変える）、X 回収、LB / RB で置く物を選ぶ、L 押し込みでスタート位置、R 押し込みで全部回収、B 購入へ戻る、Y 次へ。
  右スティックでカメラを回す、LT / RT でズーム
- コントローラーのボタンの割り当ては決まっている（キー設定の画面では右の列に表示するだけ。変えられない）
- **任天堂の配置**（M14。ユーザーの依頼：「コントローラーに任天堂のキーコンフィグを」）：設定画面の「コントローラーの配置」で **Xbox / 任天堂** を切り替える（設定ファイルに保存）。
  UE のボタンは場所で決まっている（下・右・左・上）ので、任天堂の配置では役割を入れ替える：
  | 場所 | Xbox の配置 | 任天堂の配置 |
  |---|---|---|
  | 右 | B（戻る・購入へ戻る） | **A（決定・よじ登る・置く）** |
  | 下 | A（決定・よじ登る・置く） | **B（戻る・購入へ戻る）** |
  | 上 | Y（次へ） | X（まとめて補充・回収） |
  | 左 | X（まとめて補充・回収） | Y（次へ） |
  | 肩・トリガー | LB / RB / LT / RT | L / R / ZL / ZR |
  | 真ん中 | BACK / START | － / ＋ |

  画面の案内もこの名前で出す（任天堂のボタンは色が無いので、キーと同じ板）。Switch のコントローラーを Steam などで使うとき、Steam の「Nintendo ボタン配置を使う」を **オフ**（場所のまま）にして、ゲームの方で「任天堂」を選ぶ

## ルール

- かくれんぼパートは**制限時間制**（ステージ 1 は 30 秒、ステージごとに +5 秒）
  - 制限時間まで逃げ切る → **大きな報酬**（100 × 4^(ステージ-1)）と **次のステージ**
  - 鬼に**ぶつかる（体が触れる）と即アウト**。**ペナルティなし**で、稼いだコインを持ってリザルトへ
  - **鬼に見られただけではアウトにならない**（追いかけられる）
- かくれんぼ中も移動できる（隠れ場所から出てお宝を取りに行ける）。ただし**歩くと足音が出る**（下）
- 舞台は**夜の館**。ステージが進むとマップ（家具の配置・部屋の作り）が変わる（下の「館（マップ）」）
- 最初は家具しかない大広間で、連打するしかない状態から始まる

### 足音とよじ登る音

- 歩くと 1.2m ごとに**足音**（連打の音の 50%）、よじ登ると**よじ登る音**（60%。ガサッ、トン）が出て、鬼に聞こえる
  - 鬼の種類ごとに足音の聞こえ方が違う（`OniTypes.csv` の StepHearingScale）。**宝物鬼は足音に敏感**（1.2＝標準・スピード鬼（0.6）の 2 倍。M14 は 3 倍だったが「移動が全然できない」ので下げた）、パワー鬼・探知鬼は気にしない
  - 着地も 1 歩。ダッシュ中は歩幅が広い
- **壁に囲まれた場所（空洞）にいる間は、消音壁でなくても足音・よじ登る音が 80% 小さくなる**（消音壁の方が効くならそちら。足音では消音壁は傷まない）
- **しのび足**（Ctrl または C。M15：**1 回押すとしゃがみ、もう 1 回で立つ**。設定で「押している間」にも戻せる。**パートが変わるたびに立った状態に戻る**）：速さ半分・足音 ×0.3。**しゃがむ**（体の高さ 160cm → 70cm）ので、テーブル・椅子・つぼ・トランクなど
  **体の半分くらいの高さの家具の陰にも隠れられる**（鬼が狙う頭・体・足の点も下がる。頭は床から約 63cm）。見た目はひざと腰を曲げる。頭の上に物があって立てないときはしゃがんだまま
  - **M14：しゃがむと無敵、にならないように**（ユーザーの指摘：「しゃがんだプレイヤーがなかなか見つかりにくくて無敵感が強い」）。
    1. **近くではのぞき込まれる**：鬼から **2.5m 以内**（見ている向きの中・すぐそば）なら、**腰の高さの家具（150cm より低い物）の陰にしゃがんでも見える**。壁 1 段（160cm）・本棚の陰なら見えない。
       遠くからは今まで通り隠れられる。立っている相手には使わない（立って壁 1 段の陰に隠れるのは今まで通り）
    2. **気配**：見えていなくても、鬼が**すぐそば（2.2m 以内）を通る・そばで立ち止まる**と「あやしさ」がたまり、たまると「ン？」と言ってその場所を調べに来る（近いほど速くたまる：
       1m なら約 1.4 秒、0.5m なら約 0.6 秒。さっと通り過ぎるだけなら気づかないことが多い）。間に壁 1 段・本棚があれば伝わらない。探知鬼は動かないので気配では来ない
    - 数値は OniCharacter の PeekRadius（250）・LowCoverHeight（150）・PresenceRadius（220）・PresenceRate（2.5）。テストは `CrouchFind`
  - M13：しゃがんだ体の高さ（足を床に付けるために下げる量）は元の姿勢で一度だけ測って一定にした。歩く脚の振りで毎フレーム測っていたので、家具に沿って歩くと体が上下にがくがくしていた。
    アニメーションの速さもなめらかにした（家具にぶつかって速さが 0 と少しを行き来しても、待機と歩きが入れ替わらない）
- 足音は床に控えめな青い輪で見せる。囲まれているときは左下に小さく「壁の中　足音 −80%」

### 音でわかる（M12：画面を見なくても何が来ているかわかる）

- **左右の聞こえ方**：その場所から鳴る音（鬼の足音・お宝のキラキラ・鬼が気づいた声・壁が壊れる音…）は、自前で左右に振り分ける。
  真横の音は反対の耳にはほとんど聞こえず（12%）、少し遅れて届く（最大 0.65ms。ヘッドホンだと方向がはっきりわかる）。
  向きはカメラ（画面の左右＝耳の左右）、距離は自分の体から測る
- **後ろの音はこもる**（高い音が消える）・**壁や家具の向こうの音はこもって小さい**（0.6 倍）→ 前後と、間に何かあるかも音でわかる
- **距離がわかる**：鬼の足音は 3m までは最大で、そこから**距離が 2 倍になるごとに約 -7.5dB**（10m で 22%・17m で 11%）、32m 先で聞こえなくなる。
  **遠いほどこもる**（高い「ザッ」が消えて低い「ドン」だけになる）ので、大きさとこもり具合で近いか遠いかがわかる。
  近くの音が頭打ちにならないよう、鬼の足音は大きさに余裕を持たせた（走ってくる鬼の方が大きいのはそのまま）。
  お宝のキラキラも同じ減り方で、2m までが最大（6m で 25%・15m で 8%）、28m 先で聞こえなくなる。
  鬼の足音は低い「ドスン」に床をこする高めの「ザッ」を混ぜた（低い音だけだと小さなスピーカーで聞こえず、方向もわからない）。
  うろうろしているだけの鬼の足音も大きくした。お宝のキラキラも大きく・1.2 秒ごとに
- **向かってくる鬼は足音が大きい**：音を調べに来る・怪しい所を調べる鬼は ×1.25、追いかけてくる鬼は ×1.5（少し高い音）
- **鬼が音に気づいた「ン？」**：プレイヤーの音（連打・足音・ダッシュ）に気づいた鬼が、その場所から「ン？」とうなる（4 秒に 1 回まで）。
  どっちの鬼に気づかれたかがわかる。おとりの音では鳴らない
- **見つかった「！」もその鬼の場所から鳴る**（どっちから追ってくるかわかる）
- **心臓の音（ドクン）**：鬼が近い・こちらへ向かっているほど速く大きく鳴る（画面全体で）。
  - M15（ユーザーの依頼：「鬼が近くにいるときの心音。近いほど音を大きく」）：**大きさは一番近い鬼との距離だけで決める**（20m で鳴り始め・小さい 0.15 → 2.5m 以内で 1.2。最初は 2.2 にしたが「ちょっと大きすぎる」とのことで下げた。近さの 1.3 乗なので、近づくほど急に大きくなる）。
    低い音だけだとノートパソコンのスピーカーで聞こえなかったので、胸を打つ中くらいの高さの「ドッ」とこすれる音を足した
  - 速さは危なさ ＝ 一番近い鬼の近さ ×様子（うろうろ 0.6 / 音を調べに来る 0.85 / 追いかけてくる 1.0。追われているときは遠くても 0.6 以上。身代わり人形を追っている鬼は普通）。間隔 1.15 → 0.38 秒
- 数値は GameMode（Danger〜・Heartbeat〜。HeartbeatMaxDistance・HeartbeatQuietVolume・HeartbeatLoudVolume）と OniCharacter（ChaseStepVolumeScale・InvestigateStepVolumeScale・NoticeSoundCooldown）。
  音アセットに差し替えた効果音（SoundOverrides）はエンジンの 3D の音で鳴る

### 煙幕ダッシュとよじ登る（転生のお店で解放）

- **最初はどちらも使えない**。転生のお店で買うと使えるようになる
- **煙幕ダッシュ**（Shift）：M11 でダッシュ（クールタイム制）を作り直したもの。反射神経で使う技ではなく、
  **1 ラウンドに使える回数が決まった「逃げる道具」**にした（インクリメンタル×かくれんぼ×ストラテジーなので、いつ使うかを考える）
  - **足元に煙幕を投げる**：半径 2.6m の煙が残る。**煙の中・煙の向こう側は鬼から見えない**（追いかけている鬼は見失い、最後に見えた場所＝煙を調べに行く）。
    煙は通るのを邪魔しない（ぶつかれば見つかる）。
  - 見た目は**半透明の煙**（`M_KakuSmoke`。縁ほど薄い球の集まり）。カメラとプレイヤーの間の煙は薄く（35%）、カメラのすぐ近くの煙は消すので、自分の姿と行く先は見える。
    M13：以前はカメラとプレイヤーの間の煙を隠していたので、**前へ走ると煙がちょうどその位置に残り、煙が出ていないように見えた**（「たまに出ない」）。
    残る時間（鬼の目をさえぎる時間）を過ぎても、見た目だけ 1.2 秒薄く漂ってから消える（1 秒の煙幕でも投げたのがわかる）
  - **煙が残る時間**は「煙幕ダッシュ」のレベルで **1 秒（Lv1）→ 3 → 5 → 7 秒（Lv4）**（最小 1 秒・最大 7 秒。GameMode の MinSmokeDuration / MaxSmokeDuration）
  - 同時に **1.5 秒間速くなる**（×1.4。強化では変わらない）
  - 代わりに**大きな音**が出る（連打の 1.5 倍の距離まで届く。消音壁で囲まれていれば小さくなる）→ 煙で目はごまかせても、音で寄ってくる鬼はいる
  - **回数**：1 ラウンドに 1 回。「煙幕の数」で 1 つずつ増える（最大 4 回）。ラウンドの始めに元に戻る。画面下に残りの回数（四角の数）
- **よじ登る**（Space・A。M14 でジャンプの代わり）：目の前の 1 段（175cm まで）の壁・家具の上へ、時間をかけてよじ登る
  - ユーザーの指摘：「ジャンプがあると壁から壁へ逃げられて、逃げるアクションになっている」。かくれんぼは**見つからない配置を考えるゲーム**なので、すばやく逃げる手段はやめた
  - **1 回に 1 段だけ**（2 段の壁にはまず 1 段の所へ登ってから）。**登るのに時間がかかる**：通常壁・消音壁 1 秒、家具 1.2 秒、**クライミング壁 0.3 秒**（下の「設置物」）
  - 登っている間は動けない・ダッシュできない。**登る音**（足音の 1.2 倍）が出る
  - 横に勢いは付かない（落ちるときは真下へ。歩いて落ちても隣の壁へ飛び移れない）。壁の上を歩けるのは、つながっている壁の上だけ
  - 鬼は 1 段の壁・家具には飛び乗ってくる（下の「鬼」）。**クライミング壁の上と 2 段以上の壁の上には飛び乗れない**（下から壊す）

## 鬼（AI）— 6 種類

- **M15：鬼のチュートリアル**（ユーザーの依頼：「それぞれの敵が出てくるときにチュートリアル。特徴が分かる写真と、能力の特徴」）。
  かくれんぼの始めに、**まだ紹介していない種類の鬼がいれば、ゲームを止めて「新しい鬼が来る！」の画面**を出す（何種類かいればページをめくる。Enter・→・クリックで次へ、最後は「わかった！」）。
  - **写真**：舞台のずっと下の「写真スタジオ」（`AKakurenboOniStudio`）に、種類ごとの見本の鬼を、特徴が伝わるポーズで止めて立たせ、カメラ（SceneCapture）で撮る
    （スピード鬼・標準鬼は走る・パワー鬼は振りかぶる・宝物鬼は喜ぶ・慎重鬼・探知鬼はじっと見る）。背景は種類の色。鬼のモデルが無いパソコンでは円柱の鬼が写る
  - **能力**：ひとこと・星 5 つの「足の速さ・目のよさ・耳（連打の音）・壁をこわす力」（OniTypes.csv の数値から）・特徴 3 行・**対策**（緑の行）
  - **出てから 1 秒は「つぎ」を受け付けない**（すぐ動こうとしたキーで読む前に消えないように。ユーザーの指摘。移動のキー WASD ではページをめくらない。ボタンは 1 秒薄く出る）。
  - 一度見た種類は出ない（設定に保存。「ヒントをもう一度見る」でまた出る。ヒントを表示しない設定なら出さない）。一時停止メニューの「**鬼の図鑑**」で、今まで紹介した鬼をいつでも見られる
  - テスト：`OniIntro`（全部の種類の写真を撮って確かめる）

- ステージごとに出てくる鬼の種類と数が決まっている（`Data/Stages.csv` の OniTypes 列）。並べ方は下の「レベルデザイン」
- 出現位置：**必ず鬼の出入り口から**。舞台の東側（+X）の外周の真ん中に赤い門（鳥居の形）があり、
  その前の 3×2 マス（床が赤い）に 1 体ずつ出てくる。このマスには壁も罠も置けず、スタート位置にもできない。
  かくれんぼ開始前のカウントダウン中は、門の方向を画面に表示する（「鬼の門」）。
  **門の前を壁で囲まれていても、鬼は壁を壊して出てくる**（壁に囲まれた場所にいる鬼は、まず外の広い場所へ出ようとする）
- **鬼どうしは体がすり抜ける**（違う方向へ行こうとしてすれ違うとき、押し合って動けなくならないように）
- 速さ：うろうろ 420 / 調べる 700 / 追いかける 840（標準鬼。プレイヤー 420 の 2 倍。見つかったら走って逃げ切るのは難しく、壁の陰で見失わせる）× 種類ごとの倍率 ＋ステージごとの加算

#### 勘（隠しステータス）

- ユーザーの依頼：「敵に勘というステータスを追加。プレイヤーが見えていないのにも関わらず近づいて来やすくなる。スピード鬼は低め・慎重は高め・その他は普通」。**チュートリアル・図鑑には出さない（隠しステータス）**
- うろうろ中に次の行き先を決めるとき、**勘（0〜1）の確率で、プレイヤーの本当の場所のそばのマスを行き先にする**（見えていなくても、音がしなくても）。
  そばの広さは 6 マス × (1 − 勘 / 2)（勘が高いほど近く）。歩いて行けなければ（壁で閉じこもっている）勘は外れ、いつものうろうろ。追いかけ・調べ中は使わない。探知鬼は動かないので使わない
- 値は OniTypes.csv の Intuition：**スピード鬼 0.03・慎重鬼 0.2・標準 / パワー / 探知 0.1・宝物鬼 0（勘は無い）**
- **勘は最後の駆け引き**（ユーザー：「常に発動していると逃げるのが厳しい」）。確率を 1/3 にし、一度働いたら **15 秒は働かない**（鬼の IntuitionCooldown）
- 自動テストは `Intuition` シナリオ以外では勘を切る（GameMode の bOniIntuition。うろうろの行き先がプレイヤーに寄ってほかのテストの結果が変わらないように）。
  `Intuition`：目も耳も使わない慎重鬼を 20 秒歩かせると、勘 1 は平均 7.6m・勘 0 は平均 17.6m（プレイヤーとの距離）

#### 慎重鬼の探し方（M9 で見直し）

- 歩きながら**周り 4 マスの見通せるマス**（壁・家具の向こうは見えない）を「調べた」と記録し、**慎重鬼どうしで共有**する（60 秒覚えている）
  - M14：ユーザーの「慎重鬼はシンプルにアルゴリズムが弱いかも」を受けて、2 つの案を本物の館（客間 22×22・慎重鬼 2 体・家具のとなりにしゃがんで隠れる・4 か所）で測った（`CarefulFind`）。
    ①見ている向きのマスだけ「調べた」にして着いたら大きく見回す → 平均 12.5 秒 → 18.8 秒（遅くなった）、
    ②家具のとなりを先に見る・細い道は置いた壁だけで数える → 平均 14.8 秒 → 19.0 秒（遅くなった）。どちらも採用せず、探し方はそのまま。
    今の探し方で、この館なら 7〜20 秒ほどで見つける（のぞき込み・気配の有り無しで差は無かった＝この隠れ方は普通に見えている）。
    のぞき込み・気配が効くのは、近くの背の高めの家具（110cm など）の陰にしゃがんでいる・鬼が横を通り過ぎる、といった場面（`CrouchFind` で確かめている）。
    慎重鬼が弱く感じる場面が他にあれば（館・鬼の数・隠れ方）教えてもらい、`CarefulFind` に足して測る
- 舞台を**慎重鬼の数だけ南北に分けて担当**を決め、自分の担当の、まだ誰も見ていない広い場所から回る（担当の外は後回し）
- **細い道（両側が壁・家具）・行き止まりは後回し**。うろうろ中は細い道を通るのも嫌がる（遠回りでも広い所を通る）
- **壁に囲まれた場所（空洞）は、広い場所の見残しが 12% 以下になってから**調べに行く（壊して入る）。仲間が調べている・壊している・向かっている建物には行かない
- 調べる所が残っていないとき（覚えている 60 秒の間）は、**自分の担当の区画の中を見回る**（2 体が同じ側に寄らない）
- → **たくさん置いた壁・入り組んだ通路に弱い**が、何もない広い場所に隠れているとすぐ見つかる

- **聴覚**：連打の音が聞こえる範囲（Stages.csv の OniHearingRadius × **館の大きさの倍率** × 0.75）にいると、その方向へ向かう。遠い音ほど場所が最大 3 マスずれる。
  ダッシュの音は 1.5 倍の距離まで届く。消音壁で囲まれた中の音は小さくなる。足音・よじ登る音は別の距離（StepHearingScale）で聞く
  - **M14：音の届く距離は館の大きさに合わせる**（ユーザーの指摘：「連打の音が大きすぎて、序盤のマップだと連打できない」）。
    館の一辺が 16 マス（ステージ 1）で ×0.45、40 マス（ステージ 25）で ×1.0、その間はまっすぐ増える（GameMode の MapNoiseScaleSmall / MapNoiseSmallSide / MapNoiseLargeSide）。
    連打・足音・ダッシュ・よじ登る音・おとり・床の輪が全部同じ倍率で小さくなる。ステージ 1 の連打の音は 4m（館の 1/4）くらいまで届く。家具の無いテスト用の舞台は ×1
  - 家具のすき間（家具のマスの中の、メッシュの無い所）から鳴った音は、そのそばの歩けるマスを調べに来る
- **足音**：鬼は歩くと歩幅ごとに「どたっ」と鳴る（その場所から聞こえる。20m 先で聞こえなくなる）。大きい鬼ほど低く重い
- **視覚**：懐中電灯の範囲（標準鬼は距離 900cm・正面 80 度）＋1.5m 以内は全方向。壁で遮られる。**見えたら追いかける（アウトにはしない）**
  - 視線は頭・体・足の 3 点で判定。ブロック 1 段（160cm）で体が全部隠れる
  - しゃがんでいる相手が 2.5m 以内なら、腰の高さの家具の陰でも見える（のぞき込む。M14。上の「しのび足」）
- **気配**（M14）：見えていない相手がすぐそば（2.2m 以内）にいると、あやしさがたまって調べに来る（上の「しのび足」）
- **接触**：プレイヤーにぶつかったら（体が触れたら）発見＝アウト
- **攻撃**：進路上の壁を攻撃（溜め 0.8 秒）。攻撃力は 1 × 1.6^(ステージ-1) × 種類ごとの倍率。一番下の段に当たり、壊れると上の段が落ちてくる
  - 範囲攻撃（半径 160cm）は周りの壁もまとめて壊す。慎重鬼だけは目の前の 1 個だけ、パワー鬼は前方 2×2×2（M15）
- **移動**：独自のグリッド A*（8 方向、壁の角はすり抜けない）
  - **入り口から入る**：まず壁を「通れない」ものとして経路を探す。壁に隙間（入り口）があれば、遠回りでもそこから入る
  - **他に道が無いときだけ壁を壊す**：壁で完全に囲まれている（反対側へ行けない）・相手が壁の上にいるときだけ、壁を壊す経路を使う。
    壊す経路は「攻撃 1 回 ＝ 4 マスの回り道」として、壊す回数が少ない場所を選ぶ
  - **空洞は壊して調べる**：舞台のいちばん広い空間から歩いて行けない場所（例：角に斜めに壁を置いてできた三角形の中、壁で囲んだ部屋）は「空洞」。
    うろうろ中に空洞があると、種類ごとの確率でそこを調べに行き、壁を壊して入る
  - プレイヤーが壁の上に乗ったりしても、真下でくるくる回らない（近すぎるときは向きだけ合わせて止まる）
  - **家具のすき間に入ったプレイヤー**（M14）：そばの歩けるマスまで行き、そこからまっすぐ手を伸ばす（体が触れればアウト）
  - **台の上にいるプレイヤーには飛び乗る**：家具や壁の上に立っているプレイヤーが見えたら、台のそばの歩けるマス（相手に一番近い所）まで行き、
    縁で真上に跳んで台の上に出てから相手へ向かう（`LeapMaxHeight` 280cm まで。部屋の壁 250cm・家具・壁 1 段に届く）。
    乗った台が隣の高い台につながっていれば、続けて飛び乗る。280cm より高い積んだ壁（2 段以上）は今まで通り下から壊す。
    落ちている（空中の）プレイヤーには跳ばない。**クライミング壁の上には飛び乗れない**（その壁を下から壊す。M14）

## レベルデザイン（ステージの並べ方）

プレイテストの結論：**スピードはトリモチに弱くおとりに強い、パワーはおとりに弱くトリモチに強い、慎重はたくさん置いた壁に弱いが効率よくプレイヤーを探しに来る。**
M9 で増えた鬼：**宝物鬼はお宝を守る（取りに行くなら足音を立てない・しのび足）、探知鬼は見張って仲間を呼ぶ（視線を家具や壁で切る）。**
これをもとに「1 つずつ覚える → 組み合わせで使い分けを問う」順に並べる（`Data/Stages.csv`）。
M10：全体に易しすぎたので、ステージ 3・6・8・10 に**標準鬼を 1 体ずつ足した**（難しくなりすぎないよう、少しだけ。最大 6 体は変えない）。

## 館（マップ）

- 夜の館。**ステージごとに違う館（25 個）で、ステージが進むごとに必ず大きくなる**（ステージ 1 の 16×16 マスから、1 ステージごとに縦横 1 マスずつ、ステージ 25 の 40×40 マスまで）。
- **M14：本物の館らしく**（ユーザーの依頼：「今はものが雑多に置かれている一室みたい。もっと本物の館っぽく」）。どの館も
  - **鬼の門（東）の前が玄関ホール**（石の床・柱・植木・大時計・長いす）。そこから**廊下**（寄木の床）が西へのび、大きな館では枝分かれする
  - 廊下の両側に**役割のある部屋**：居間・書斎・寝室・子ども部屋・食堂・台所・浴室・書庫・物置・客間・地下室・礼拝堂…。館の名前の部屋（居間・大広間・王の間…）が一番大きい
  - **部屋ごとに家具の決まり**：寝室はベッド（頭を壁に）・衣装だんす・たんす、食堂は長い食卓と両側の椅子・食器棚、台所はかまど・調理台・樽、浴室は浴槽と洗面台（タイルの床）、書庫は本棚の列…
  - **出入り口**は 1〜2 マス（木の枠・石のアーチ。上には壁がある）、**床は部屋ごと**（板張り・寄木・石・タイル）、**壁は壁紙＋腰壁（木の板）＋縁**、外周の壁には窓（夜空）、壁に絵と松明の明かり
  - **家具の量はどの館もだいたい同じ**（床のマスの 20〜24%）。**転生の壁のステージ（8・13・18・23）だけ少なめ**（15〜17%。ユーザーの希望：「転生してほしいところは気持ち少な目で」）
  - 家具の中に入れる家具（中に入って周りを壁で囲う遊び方になる）は作らない（ユーザーの判断）
- マップごとに**家具（本棚・テーブル・暖炉・トランク…）と部屋の壁**が置いてあり、**壊せない・通れない**（鬼もプレイヤーも）。
  壁や罠は家具のマスには置けない。家具の陰は隠れ場所になる（低い家具＝テーブル・椅子・つぼはしゃがめば隠れられる）。前半の館は背の高い家具を多めにした
- **部屋の壁（`#`）は外周の壁と同じ高さ（10m）まである**（M12）。上に乗って逃げられず、隣の部屋も見えない（三人称カメラも通さない）。
  高い部分は外周と同じく、上から見下ろす購入・設置・リザルトでは隠す
- 三人称カメラは家具をすり抜ける（家具の陰にしゃがんでも自分が見え、カメラが家具に当たってがくがくしない）
- マップは `Data/Maps.csv`（名前・床と壁紙と明かりの色・床と壁の模様・間取りのファイル）と `Data/Maps/*.txt`（間取りを文字で描いたもの。**文字数 × 行数が館の大きさ**）。
  家具は `Data/Furniture.csv`（間取りの 1 文字 → メッシュ・高さ・明かり）。書き方は Data/README.md。
  **間取りは `Tools/GenerateMansion.py` が作る**（M14。玄関ホール → 廊下 → 部屋を区切る → 部屋の役割と家具 → 出入り口 → 鬼の門から全部の床へ歩いて行けるか → 家具の量をそろえる。乱数は館の名前から決まる）。
  間取りの後ろの `[floor]` に床の種類（`Data/FloorKinds.csv`）。手で直してよい（作り直すと上書きされる）
- **館が変わると**（購入パートに入るとき）、置いていた壁と罠は**在庫に戻り**、前のマップの**設計図はとっておく**（そのマップに戻ったら在庫から自動で直る）。
  大きさが変わると床・外周の壁・門を作り直し、門の場所も変わる（門の前・館の外になった壁や罠は在庫に戻る）
- 家具の見た目は Fab の「Stylized Library」「Medieval Room Kit」「Stylized House Interior（StylizedKitchen）」「Isometric Interiors」から、手描き風でそろう物を選んだ（下の「見た目のアセット」）。無い場合は色の付いた箱で表示する
- 壁の飾り（窓・絵・松明・出入り口の枠）は `Data/Decor.csv`。窓は外周の壁だけ（4 マスごと）、松明は 6 マスごと（館に 64 個まで）、絵はその間。背の高い家具の後ろ・出入り口の横には付けない
- **出入り口の上の壁**（M14。ユーザーの指摘：「扉がインゲーム中だと上に何もなく、そこにあるだけに見える」）：部屋の壁は天井（10m）まであるのに、出入り口だけ天井まで抜けていて、枠だけが立って見えた。
  枠のてっぺんから天井まで、両側に壁紙を貼った壁を付けた。外周の壁の高い部分と同じく、かくれんぼ中だけ見せる（上から見下ろす設置パートでは出入り口が見える）。
  当たり判定はカメラだけ（出入り口に置いた壁・よじ登る・鬼の飛び乗りの邪魔をしない）
- 長い家具（"BBBB" の本棚の列）は同じメッシュを何個か並べ、家具の正面は部屋の空いている側へ向ける。
  **メッシュは必ずマスちょうど（1 マス・2 マス…）に収める**（マスの境目にまたがって置くと、空いて見えるマスに壁が置けないため。長い辺は少しだけ伸ばしてマスを埋める）
  - M13：**短い辺の方向も同じ**にした。2×2・3×2 のテーブルやトランクの山は、メッシュが高さで決まる大きさのまま真ん中に 1 個だけ置かれ、
    **マスの境目にまたがって 2 マスぶんの場所を取って見えた**。メッシュが 2 マスを埋めるほど大きくならないときは、**マスごとに 1 個ずつ並べる**（2×2 なら 4 個）。
    全部の館でまたがっているメッシュが無いことをテストで確かめている（Maps）
  - M14：**長い辺は 0.6〜1.5 倍、短い辺は 0.6〜1.3 倍まで伸び縮みさせてよい**ことにし、「伸ばして埋められる一番少ない数」に分ける（1 個はいつも整数のマス。割り切れなければ 3 マス＋2 マス）。
    幅 2m の本棚を 1 マスに置いても背の高さ（当たり判定の高さ）のまま見える・2×2 のベッドが 2 つに分かれない・1 マスの奥行きの調理台が小さくなりすぎない
  - M14：**後ろが壁・家具の家具は後ろの壁にぴったり付ける**（奥行きの余りは前にできる）
  - M14：**当たり判定は見えているメッシュ 1 個ずつの大きさ**（上から見た外形 × 家具の高さ）。ユーザーの依頼：「本棚の隙間には入れるように」。
    見えている床（浅い本棚・たんすの前、家具と家具のすき間）には入れる。マスとしては家具のマスのまま（壁・罠は置けない・鬼の経路は通らない）。
    鬼はそばの歩けるマスまで来て手を伸ばす。全部のメッシュの家具の当たり判定を数えてテストで確かめている（Mood・Lineup）
  - M15：**背の高い家具（150cm 以上：本棚・たんす・食器棚・大時計・暖炉）の前のすき間は「体が入る（78cm 以上）」か「無い」かのどちらか**にした（ユーザーの指摘：「本棚の隙間が入れない」）。
    浅い家具の前に 30〜50cm のすき間があり、床が見えているのにしゃがんでも体（直径 70cm）が入らなかった。後ろが壁なら奥行きを薄く（最低 20cm）して前に 78cm 空け、
    真ん中に立っている家具・薄くしきれない家具はすき間を無くす（すき間が 20cm より狭いものは今まで通り）。25 の館の全部の背の高い家具で確かめている（`ShelfGap`）。数値は Arena の TallFurnitureHeight・FurnitureWalkInGap・MinShelfDepth
  - **背の高い家具を長い辺に何個か並べたときの、間のすき間も同じ**（ユーザーの指摘：「この本棚の隙間に入れるように」。伸ばしきれない本棚の間に 34〜37cm のすき間が 7 つの館に 19 か所あった）。

  - **L 字の角の本棚（本棚 B の AltMesh・SM_Bookcase_02）の当たり判定は L 字**（ユーザーの依頼：「この本棚の当たり判定を L 字に」）。

## 設置物

- **グリッドに沿って配置**（1 マス = 幅 100cm × **高さ 160cm（プレイヤーの背と同じ）**、館の大きさのマス数（16×16〜31×29）、最大 3 段）
- プレイヤーは**よじ登る**（転生のお店で解放）でブロック 1 段に登れる
- 設置パートは真上から見下ろし、プレイヤーは表示しない。かくれんぼを始める場所（スタート位置）は床の青い印で示し、T でカーソルのマスへ動かす
- 照準の先にプレビュー（緑: 置ける / 赤: 置けない / 黄色の枠: 回収できる壁）。スタート位置・鬼の出入り口の前・家具のマスには置けない
- M15：**カーソルのレイは見えていない物には当てない**（ユーザーの指摘：「Unity でいう ray が悪くてブロックが置けない」）。設置パートでは外周・部屋の壁の高い部分（10m）を隠しているだけで当たり判定は残っていて、
  斜めのレイがその見えない壁に当たり、手前の別のマス（家具のマス）を指していた。見えていない物に当たったら、それを無視してもう一度飛ばす（家具の当たり判定の箱は隠してあるが、見えている家具と同じ形なので当てる）。`BuildRay` で確かめている
- **設計図（配置の保存）**：プレイヤーが置いた・回収したときの状態を覚えておく。鬼に壊されても設計図は残る
- **自動修復**：設置パートの開始時に、壊れた壁を設計図どおりに**在庫から**作り直す
  - 購入パートで買い足した在庫も使える。在庫が足りない分は**赤い枠**で表示（手で置き直すか、次回在庫があれば直る）
  - **赤い枠のマス（設計図だけで、今は何も無いマス）に別の物を置くと、そのマスの設計図は自動で消えて、置いた物が新しい設計図になる**
    （壊れた壁の跡に罠・使った罠の跡に壁など。ユーザーの希望。右クリックで消してから置かなくてよい）
  - プレイヤーが立っている（上に乗っている）列は、閉じ込めないよう直さない
  - 手で置いたり回収したりした列は、その状態が新しい設計図になる

M14：ユーザーの依頼で**壁は 3 種類**にした（「数ではなく、考えて配置することで敵に見つからないようにする」）。木・石・鉄の「硬さ違い」はやめ、**働きの違う壁**にした。

| 壁 | 耐久 | 価格（1 個目 × 持っている数ごとの倍率） | よじ登る | 特徴 |
|---|---|---|---|---|
| **通常壁** | 3 | 15 × 1.12 | 1 秒 | 基本の壁。たくさん置いて形を作る |
| **消音壁** | 3 | **150** × 1.5 | 1 秒 | 囲まれた中の音を小さくする。**60 回音を消すと壊れる**（下） |
| **クライミング壁** | 1.5 | 40 × 1.15 | **0.3 秒** | はしご付きの壁（横木が見える）。すばやく上へ逃げられるが、**鬼は上に飛び乗れず、下から壊す**（もろい）。よじ登るを解放するまで買えない |

- M14：館の大きさで連打の音が小さくなった（小さい館では元から音が届きにくい）ので、消音壁の出番が減った（ユーザーの指摘：「消音壁がちょっと弱くなったかも」）。
  **値段を 300 → 150、音を消せる回数を 40 → 60** にした（早いうちから買えて、長持ちする）。音を小さくする割合（80%）はそのまま
- **壁の耐久 ＝ 表の耐久 × 壁の補強（足し算）× 壁の硬さ（掛け算）**（M14。ユーザーの案：「転生の壁強化を倍率に、通常強化で実数値強化」）
  - **壁の補強**（コインのお店）：1 Lv ごとに **+50%**（×1 → 1.5 → 2 → 2.5…。価格 40 × 1.9^Lv。`Upgrades.csv` の Wall 行）。置いてある壁もすぐ硬くなる。転生でなくなる
  - **壁の硬さ**（転生のお店）：×1.5^Lv（転生しても残る）
  - 購入パート・設置パートに「耐久 〇（〇 発）」＝今のステージの標準鬼に何発で壊されるかを出す
- 鬼の攻撃力はステージごとに ×1.6 なので、補強だけでは追いつかなくなる → 転生して「壁の硬さ」を上げる、がインクリメンタルの流れ
- **壁も買うほど高くなる**（持っている数 ＝ 在庫＋置いてある数。壊れた分は数えないので、買い直しの値段は上がらない）
- 版 5 までのセーブの壁の在庫・配置は、消音壁はそのまま、ほかの壁（木・石・鉄）は通常壁に置き換える

### 消音壁

- プレイヤーが**壁に囲まれた空洞の中にいるときだけ**効く（囲まれていなければ効かない）
- 空洞を囲んでいる壁（空洞のマスの周り 8 マスにある壁。積んだ列は一番下の段の種類）のうち、
  消音壁の割合だけ連打・ダッシュの音が小さくなる：**音の大きさ = 1 − (囲んでいる壁の NoiseDamping の平均)**。
  消音壁（0.8）だけで囲めば 80% 小さくなる（音の届く距離が 1/5）。半分なら 40%
- 床に出る音の輪も小さくなり、左下に小さく「消音壁の中　音 −〇%（あと〇回）」と出る
- おとりの音には効かない
- **音を消すたびに傷み、回数が尽きると壊れる**：囲んでいる消音壁（一番下の段）それぞれの「音を消せる回数」が、連打 1 回で 1、ダッシュ 1 回で 3 減る。
  基本は 60 回（`Walls.csv` の SoundHP。M14 で 40 → 60）で、転生のお店の「消音壁の丈夫さ」で ×1.5 ずつ増える。壊れると囲みに穴が開く（設計図には残るので、在庫があれば次の設置パートで直る）。
  傷むほど色が暗くなる

### 罠

  当たり判定は無く、プレイヤーも鬼も上を通れる。右クリックで回収（残っていれば在庫に戻る）
- **価格は持っている数（在庫＋置いてある数）が増えるほど上がる**（トリモチ ×1.5・おとり ×1.6 ずつ）。置きすぎて鬼がずっと動けない、を防ぐ
- 使った罠は設計図に残り、次の設置パートで在庫があれば自動で置き直す（在庫が無ければ赤い枠。右クリックで設計図から消せる）

| 罠 | 価格 | 働き |
|---|---|---|
| トリモチ | 150（× 2.2） | 鬼が上を通ると **4 秒動けない**（頭の上で星が回る。種類で長さが変わる）。その間は触れても捕まらない。1 回で消える。抜け出した鬼は 3 秒間かからない（パワー鬼はこの間に踏んだトリモチを壊す） |

## 視点

- **俯瞰**（購入・リザルト）：斜め上 60 度から自分を見下ろす。Q/E・マウスの左右・ホイールを押してドラッグで回転、ホイールでズーム
- **真上から**（設置）：舞台全体が入る高さから真下を見る。**プレイヤーは表示しない**（スタート位置は床の青い印）。
  WASD でカメラを画面の向きに動かす、Q/E・ホイールを押してドラッグ（左右）で回転、ホイールで高さを変える。
  **Z で斜めに傾ける・X で真上に戻す**（ホイールを押して上下にドラッグでも。真上 −90 度〜 −25 度）。積んだ壁の高さが見やすい。傾きは設置パートをまたいで覚えておく。
  カーソルを表示し、カーソルの指すマスにプレビューを出す
- **三人称**（かくれんぼ）：自分の背後の少し上から見る。マウスで回す、ホイールで距離を変える。WASD はカメラ基準
  - **置いたブロックはカメラがすり抜ける**ので、壁で囲んでも外から自分と周りが見える

  - **M14：壁ぎわでカメラが揺れない**（ユーザーの指摘：「カメラがグワングワンする」）。下の「カメラの揺れの直し方」

    左上の一覧には鬼の様子（うろうろ / 音に気づいた / 追いかけてくる / お宝の周りを回っている / 見張っている…）だけを出す
  - 連打の手応えは画面に浮かぶ「+〇」で出す（カメラは揺らさない）
- 見た目の調整：夜の館（上の「雰囲気」）。モーションブラーなし

### カメラの揺れの直し方（M14）

- **原因**：館を部屋に分けたので、三人称カメラ（アームの先のカメラ）が部屋の壁に当たることがとても増えた。
  アーム（UE の SpringArm）の当たり判定は、**壁に当たるとその場で手前に縮め、当たらなくなった瞬間に元の長さ（5.5m）へ戻す**。
  廊下や壁ぎわを歩く・カメラを回すと、毎フレームのように「縮む → 戻る」をくり返し、カメラが前後に大きく揺れていた
- **直したこと**（`AHiderCharacter::Tick` の三人称の所）：
  1. 毎フレーム、注視点（体の中心＋70cm）からカメラの方向へ、カメラと同じ太さの球を飛ばして（`SweepSingleByChannel`・カメラ用の当たり判定）、**壁に当たらない長さ**を自分で測る
  2. **壁に当たって縮めるときはすぐ**（壁の中にカメラが入らないように）、**壁から離れて伸ばすときはゆっくり**（`FInterpTo`。速さ `CameraReturnSpeed` = 2.5。0.3 秒で約半分、1 秒でほぼ元の距離）
  3. フレームが引っかかったとき（シェーダーの準備など）に一気に戻らないよう、伸ばすときに使う時間は 1 フレーム 1/20 秒まで
  4. ホイールで変えた距離へのなめらかな近づき方は、壁の長さとは別に持つ（`ZoomArmLength`）。アームの当たり判定は念のため残した（測った長さより先に壁があれば、そこでも止まる）
  5. 視点が変わったら（購入・設置 → かくれんぼ）測り直す
- 家具はカメラが通り抜ける（前から）。出入り口の上の壁はカメラだけ当たる
- テスト：`CameraWall` シナリオ（後ろが部屋の壁の場所でカメラが寄る → 向きを変えたら 0.12 秒では元に戻りきらない＝跳ねない → 2.5 秒で元の距離）
- 舞台の外周の上に見えない柵（プレイヤーとカメラは通さない。カーソルや鬼の視線は通す）

| プレイヤーの足音・よじ登る | 控えめな青い輪 | トッ（小さく） / ガサッ、トン |
| 鬼が歩く | — | **どたっ**（その場所から。大きい鬼ほど低い。向かってくる鬼は大きい） |
| 鬼が音に気づく | — | **「ン？」**（その鬼の場所から） |
| 鬼が近い・向かってくる | — | **心臓の音「ドクン」**（近いほど速く大きく） |
| 鬼が追いかけてくる | **目が赤く光る**・顔のまわりが赤い | 「！」（その鬼の場所から） |
| メニュー・設定 | 画面を暗くしてパネル | ボタンの音 |
| お宝 | 光る・回る | **キラキラ**（その場所から 1.6 秒ごと） |
| 探知鬼が仲間を呼ぶ | 紫の大きな輪・「探知鬼に見つかった！ 鬼が〇体集まってくる！」 | サイレン「ウーッ」 |

- 鬼・壁・罠・お宝の音はその場所から（**M12 から自前で左右に振り分ける**。左右の大きさの差・耳に届く時間の差・後ろや壁の向こうはこもる。上の「音でわかる」）。鬼の足音は 32m・お宝のキラキラは 28m 先で聞こえなくなる。それ以外は画面全体で鳴る
- **BGM**（プログラムで作った曲をくり返す）：購入・設置・リザルトは「夜の館のおもちゃ箱」（Am−F−C−E、100 BPM、オルゴールとはねるベース）、
  かくれんぼは速くて少し怖い曲（Dm−B♭−Gm−A、126 BPM、刻むベースと太鼓・鐘）。パートが変わると 1 秒かけて切り替わる
- 音量は**設定画面**（全体・BGM・効果音）で変えられる。コンソールの `KakuVolume 0〜1`（全体）・`KakuMusicVolume 0〜1`（BGM）でも。
  一時停止中も BGM は流れ続ける（タイマーが止まるので PlayerController が波形を足す）
- 設置パートのグリッド線・プレビューの枠は開発用の描画機能を使っている（Shipping ビルドでは出ないので、配布前にメッシュに置き換える）

## インフレさせる要素（購入対象）

購入パートの並び（数字キー）: 1 連打コイン強化 / 2 時間コイン強化 / 3 壁の補強 / 4〜6 壁（通常・消音・クライミング） / 7〜8 罠

- 連打 1 回あたりのコイン（価格 15 × 1.7^Lv）
- 時間あたりのコイン（価格 25 × 1.7^Lv）
- 壁の補強（+50% ずつ。上の「設置物」）
- 壁（上の表）
- 罠（上の表。持っている数が増えるほど高くなる）
- 壁と罠の行には「壊れた（使った）〇個（直すにはあと〇個）」を出す。在庫で直せるなら緑、足りなければ橙
- 商品の行・タブ・下のボタン（まとめて補充 / 転生する / 設置パートへ）はマウスでクリックできる（カーソルを乗せると明るくなる）。
  ボタンの位置はお店を切り替えても・転生できるようになっても動かない
- **まとめて補充（R）**：壊れた壁・使った罠を直すのに足りない分を、**値段の高いものから**買えるだけ買う。下に「あと〇個（〇コイン）」と出る（宝石の道具は買わない）
- **まとめ買い（M15。ユーザーの依頼）**：上の **［×1］［×10］［最大］** を選ぶと、商品をクリックしたときにその数だけ買う（強化はレベルを、壁・罠は個数を。1 個ずつ値上がりしながら、買えるところまで）。
  ×10・最大のときは値段の欄に「×買える数　合計」を出す。宝石のお店でも使える。転生のお店は 1 つずつ
- M15：**文が枠からはみ出す・かぶるのを直した**（ユーザーの指摘）。長い文は枠に収まる大きさまで小さくし（6 割まで）、それでも入らなければ「…」。商品の説明は値段の列の手前まで（「クリックで買う」とかぶらない）・長ければ 2 行に。
  設置パートの案内の枠は中の文の幅に合わせ、下の欄の名前・在庫も欄に収める。カーソルの下の案内は画面の端で切れないように内側へ寄せる。ステータスの宝石の数がタイトルとかぶらない位置に
- 数値は `KakurenboIncremental/Data/*.csv`（Stages / Upgrades / Walls / OniTypes / Traps / Prestige / PrestigeUpgrades / Maps / Furniture / Surfaces / FloorKinds / Decor）と `Data/Maps/*.txt` で調整する。書き方は Data/README.md

## 宝石と宝石のお店（M15）

ユーザーの依頼：「宝石の価値がなさすぎて取りに行く必要がないので、宝石ショップで強いアイテムを交換できるように」「宝石全取得でボーナス」。
道具は 3 つがユーザーの案、2 つ（迷い猫・だるまさんがころんだ）は Claude の案（「強いじゃなくて突飛なアイディアで」）。

- **宝石**：お宝 1 個で 1 つ（お宝ではコインはもらえない）。**そのラウンドのお宝を全部取ると、ボーナスの宝石 +2**（「お宝コンプリート！」）。見つかっても取った分はもらえる。

- **宝石のお店**：購入パートの真ん中のタブ（コイン → 宝石 → 転生）。価格は宝石で、持っている数が増えるほど上がる。道具は `Data/Traps.csv` の **bGemItem = True** の行（罠と同じしくみ：在庫・設置・設計図・自動で置き直し・セーブ）
- 設置パートの下の欄には、持っている宝石の道具だけが並ぶ（だるまさんがころんだは置かないので出ない）

| 道具 | 宝石（1 個目 × 倍率） | 置き方 | 働き |
|---|---|---|---|
| **身代わり人形** | 3 × 1.5 | 床のマス | 自分そっくりの人形（少し色が薄い）。鬼からはプレイヤーに見える。**見つかると、置いたときに向いている方へまっすぐ逃げる**（ユーザーの希望。のれんと同じく床の矢印で向きを決めて置き、置いた人形をクリックすると 90 度回る。前は鬼と反対の方へ逃げていた。680cm/秒。ユーザーの希望で 480 から速くした。プレイヤーの歩き 420・鬼が追いかける 840。ぶつかったら置いた向きに近い向きへ変える。後ろ向きには逃げない）。**逃げている間は大きな音（ドタバタ。連打の 1.3 倍）を出し続ける**ので、周りの鬼も寄ってくる（ユーザーの希望）。鬼に捕まると「ポン」と消え、鬼は「にせもの！？」と見回す（そのラウンドは消えたまま。在庫があれば次の設置で置き直し）。プレイヤーが見えたら、鬼はプレイヤーを追う方を選ぶ |

## 転生（プレステージ）

- **ステージ 5 から**、購入パートで **P を 2 回**（または「転生する」ボタンを 2 回）押すと転生できる（1 回目は確認。3 秒以内にもう一度）
- **転生ポイント = 今のステージ − 4**（ステージ 5 で 1、ステージ 8 で 4）をもらう
- **はじめのコインは転生した回数ぶん増える**（M13。強化ではなく自動）：転生した後は **転生した回数 × 500 コイン**から始まる（1 回目 500・2 回目 1,000・4 回目 2,000）。
  `Data/Prestige.csv` の StartCoinsPerPrestige。購入パートの説明と転生のお知らせに出す
- 転生すると**コイン（はじめのコインになる）・ステージ・強化・壁と罠の在庫・置いてある壁と罠がなくなり**（宝石と宝石の道具は残る）、**まず転生のお店が開く**（もらったポイントを使ってから、設置 → ステージ 1 のかくれんぼ）。
  **設計図（配置）は残る**ので、在庫を買い直せば設置パートで自動で直る
- 左上に「転生〇回・転生ポイント〇pt」を出す。数値は `Data/Prestige.csv`

### 転生のお店（永続強化）

購入パートの「転生のお店」タブ（Tab かクリック）で、転生ポイントを使って買う。**転生しても残る**。
価格 = 切り上げ(BaseCost × CostGrowth^レベル)、効果 = BaseValue × ValueGrowth^レベル（`Data/PrestigeUpgrades.csv`）

| 強化 | 最大 | 価格（pt） | 効果 |
|---|---|---|---|
| 壁の硬さ | なし | 1, 2, 3, 4, 6… | すべての壁の耐久 ×1.5^Lv（置いてある壁もすぐ硬くなる）。1 Lv で鬼の攻撃力の伸び（×1.6/ステージ）にほぼ 1 ステージぶん追いつく |
| お宝の宝石 | なし | 2, 4, 6, 9… | お宝 1 個でもらえる宝石 1 → 2 → 3 …（**足し算**：1 + Lv。M15：お宝がコインではなく宝石になったので「お宝の価値 ×1.5」から変えた）。**全部取ったボーナスも同じ割合で増える**（2 → 4 → 6 …。ユーザーの希望） |
| 煙幕ダッシュ | 4 | 2, 4, 6, 9 | **Lv1 で煙幕ダッシュが使えるようになる**。煙が残る時間 1 → 3 → 5 → 7 秒（**足し算**：BaseValue + ValueGrowth × (Lv − 1)） |
| 煙幕の数 | 3 | 2, 4, 8 | 1 ラウンドに使える回数 1 → 2 → 3 → 4（**ここだけ足し算**：BaseValue + ValueGrowth × Lv） |
| よじ登る | 1 | 2 | **よじ登れるようになる**（M14。ジャンプの代わり）・クライミング壁が買えるようになる |
| 消音壁の丈夫さ | なし | 1, 2, 3, 4, 6… | 消音壁が音を消せる回数 ×1.5^Lv（40 → 60 → 90…。置いてある壁も） |
| 連打のお金アップ | なし | 1, 2, 3, 4, 6… | 連打で稼げるコイン ×1.5^Lv（コインの「連打コイン強化」の上に掛かる。ユーザーの依頼） |
| 時間のお金アップ | なし | 1, 2, 3, 4, 6… | 時間で稼げるコイン ×1.5^Lv（コインの「時間コイン強化」の上に掛かる。ユーザーの依頼） |

## パッケージ化（配布用の .exe）

UE エディタが無いパソコンでも遊べる形にする。

```powershell
cd C:\KakurenboIncremental
powershell -ExecutionPolicy Bypass -File Tools\Build.ps1     # 先にエディタ側をビルド
powershell -ExecutionPolicy Bypass -File Tools\Package.ps1   # パッケージ化（-Config Shipping も指定できる）
```

- 出来上がり: `Packaged/Windows/KakurenboIncremental.exe`。配るときは `Windows` フォルダごと渡す（`Packaged/` は Git に入れない）
- 初回はシェーダーの準備などで数十分かかる。2 回目からは速い
- エディタのメニュー（プラットフォーム → Windows → パッケージプロジェクト）ではなく、必ずスクリプトを使う
  - バランスの CSV（`Data/*.csv`）はアセットではないので自動では入らない。スクリプトが `KakurenboIncremental/Data` にコピーする
    （無いとプログラムの既定値で動き、CSV と違うバランスになる）
- 鬼の見た目（`Content/CuteCreature`）と家具（`Content/Stylized_Library`）はパスでしか参照していないので、DefaultGame.ini の `DirectoriesToAlwaysCook` で必ず入れている。
  そのパソコンに Fab アセットが無ければ、円柱の鬼・箱の家具のまま入る。間取り（`Data/Maps/*.txt`）も Data フォルダごとコピーされる
- **今は Development で作る**。Shipping では開発用の描画（設置パートの枠・グリッド線）が出ないので、メッシュに置き換えてから Shipping にする
- パッケージ版のセーブはエディタで遊んだセーブとは別の場所に保存される
