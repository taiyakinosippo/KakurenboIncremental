# かくれんぼインクリメンタル 設計書

## コンセプト

プレイヤーは**隠れる側**。鬼から逃げ切りながらコインを稼ぎ、ブロックや強化を買って
隠れ場所をインフレさせていく 3D インクリメンタルゲーム。

核となるジレンマ：**連打すれば稼げるが、音で鬼を呼び寄せる。お宝を取りに行けば稼げるが、隠れ場所から出ることになる。**

## ゲームループ

```
（最初だけ）[かくれんぼ] → [リザルト] → [購入] → [設置] → [かくれんぼ] → …
```

| パート | 視点 | プレイヤーの操作 | 内容 |
|---|---|---|---|
| 購入 | 俯瞰 | **クリック**・数字キーで購入 / Tab・タブのクリックでお店の切り替え / P を 2 回・ボタンで転生 / Enter・ボタンで次へ | 「コインのお店」で強化・壁・罠、「転生のお店」で永続強化を買う。**壊れた壁・使った罠の数を種類ごとに表示**。ステージ 5 から転生できる |
| 設置 | **真上から**（Z/X で斜めに傾けられる。プレイヤーは表示しない） | WASD でカメラを動かす、カーソルでマスを指して置く・回収、**下の欄をクリック**・数字キーで置く物を選ぶ、T でスタート位置を動かす、ボタン・Enter で開始、**ボタン・B で購入パートへ戻る** | 壁と罠をグリッドに置く・回収する。**壊れた壁・使った罠は開始時に在庫から自動で直す**。購入パートへ戻っても置いた壁・罠はそのまま |
| かくれんぼ | **三人称** | WASD で移動、**Ctrl でしのび足**、（解放したら）Space でジャンプ・Shift で煙幕ダッシュ（回数制）、左クリック / F で連打、マウスでカメラ | 時間・連打・お宝でコインを得る。開始 3 秒後に**赤い門（鬼の出入り口）から**鬼が出てくる（種類と数はステージごと）。**鬼とお宝の場所は矢印では出ない。足音とキラキラの音で見当をつける** |
| リザルト | 俯瞰 | Enter で次へ | 獲得コイン・お宝・壊された壁・使った罠の数を表示。クリアなら次のステージへ |

## ルール

- かくれんぼパートは**制限時間制**（ステージ 1 は 30 秒、ステージごとに +5 秒）
  - 制限時間まで逃げ切る → **大きな報酬**（100 × 4^(ステージ-1)）と **次のステージ**
  - 鬼に**ぶつかる（体が触れる）と即アウト**。**ペナルティなし**で、稼いだコインを持ってリザルトへ
  - **鬼に見られただけではアウトにならない**（追いかけられる）
- かくれんぼ中も移動できる（隠れ場所から出てお宝を取りに行ける）。ただし**歩くと足音が出る**（下）
- 舞台は**夜の館**。ステージが進むとマップ（家具の配置・部屋の作り）が変わる（下の「館（マップ）」）
- 最初は家具しかない大広間で、連打するしかない状態から始まる

### 足音とジャンプの音

- 歩くと 1.2m ごとに**足音**（連打の音の 50%）、ジャンプすると**ジャンプの音**（70%）が出て、鬼に聞こえる
  - 鬼の種類ごとに足音の聞こえ方が違う（`OniTypes.csv` の StepHearingScale）。**宝物鬼は足音に敏感**（2.2 倍）、パワー鬼・探知鬼は気にしない
  - 着地も 1 歩。ダッシュ中は歩幅が広い
- **壁に囲まれた場所（空洞）にいる間は、消音壁でなくても足音・ジャンプの音が 80% 小さくなる**（消音壁の方が効くならそちら。足音では消音壁は傷まない）
- **しのび足**（Ctrl または C を押しながら歩く）：速さ半分・足音 ×0.3
- 足音は床に控えめな青い輪で見せる。囲まれているときは画面上部に「壁に囲まれている：足音が 80% 小さい」

### 煙幕ダッシュとジャンプ（転生のお店で解放）

- **最初はどちらも使えない**。転生のお店で買うと使えるようになる
- **煙幕ダッシュ**（Shift）：M11 でダッシュ（クールタイム制）を作り直したもの。反射神経で使う技ではなく、
  **1 ラウンドに使える回数が決まった「逃げる道具」**にした（インクリメンタル×かくれんぼ×ストラテジーなので、いつ使うかを考える）
  - **足元に煙幕を投げる**：半径 2.6m の煙が残る。**煙の中・煙の向こう側は鬼から見えない**（追いかけている鬼は見失い、最後に見えた場所＝煙を調べに行く）。
    煙は通るのを邪魔しない（ぶつかれば見つかる）。カメラとプレイヤーの間・カメラのすぐ近くの煙は隠れるので、自分の姿と行く先は見える
  - **煙が残る時間**は「煙幕ダッシュ」のレベルで **1 秒（Lv1）→ 3 → 5 → 7 秒（Lv4）**（最小 1 秒・最大 7 秒。GameMode の MinSmokeDuration / MaxSmokeDuration）
  - 同時に **1.5 秒間速くなる**（×1.4。強化では変わらない）
  - 代わりに**大きな音**が出る（連打の 1.5 倍の距離まで届く。消音壁で囲まれていれば小さくなる）→ 煙で目はごまかせても、音で寄ってくる鬼はいる
  - **回数**：1 ラウンドに 1 回。「煙幕の数」で 1 つずつ増える（最大 4 回）。ラウンドの始めに元に戻る。画面下に残りの回数（四角の数）
- ジャンプ（Space）：ブロック 1 段に飛び乗れる

## コイン収入

| 収入源 | 内容 |
|---|---|
| 時間収入 | 隠れている間、毎秒一定額を得る（1 × 1.5^Lv） |
| 連打収入 | 1 回ごとに得る（1 × 1.5^Lv）。**押すたびに音が出る** |
| お宝 | 毎ラウンド **3〜4 個**（ステージごと）がランダムな空きマスに出現。ときどきキラキラと鳴る。1 個 = 逃げ切り報酬 × 0.3。プレイヤー・他のお宝から 4 マス以上離れた場所。取れなかった分はラウンド終了で消える |
| クリア報酬 | 逃げ切ったときにまとめて得る大きな報酬 |

## 鬼（AI）— 6 種類

- ステージごとに出てくる鬼の種類と数が決まっている（`Data/Stages.csv` の OniTypes 列）。並べ方は下の「レベルデザイン」
- 出現位置：**必ず鬼の出入り口から**。舞台の東側（+X）の外周の真ん中に赤い門（鳥居の形）があり、
  その前の 3×2 マス（床が赤い）に 1 体ずつ出てくる。このマスには壁も罠も置けず、スタート位置にもできない。
  かくれんぼ開始前のカウントダウン中は、門の方向を画面に表示する。
  **門の前を壁で囲まれていても、鬼は壁を壊して出てくる**（壁に囲まれた場所にいる鬼は、まず外の広い場所へ出ようとする）
- **鬼どうしは体がすり抜ける**（違う方向へ行こうとしてすれ違うとき、押し合って動けなくならないように）
- 速さ：うろうろ 420 / 調べる 700 / 追いかける 840（標準鬼。プレイヤー 420 の 2 倍。見つかったら走って逃げ切るのは難しく、壁の陰で見失わせる）× 種類ごとの倍率 ＋ステージごとの加算

### 種類（パックマンの鬼のように性格が違う）

| 種類 | 色 | 速さ | 壁を壊す力 | 探し方 |
|---|---|---|---|---|
| **標準鬼** | 赤（黒） | ×1.0 | ×1.0（範囲） | 近くをうろうろ。音に寄ってくる。空洞は 50% で調べる |
| **スピード鬼** | 水色（青） | ×1.25 | ×0.5（範囲） | **大雑把に全体を見て回る**：舞台を 4×4 マスの区画に分けて、しばらく行っていない区画へ走る。視界が広い（1300cm・110 度）。空洞は調べない。**音に敏感**：プレイヤーの音が 1.5 倍の距離まで聞こえ、**おとりはにせものとわかる（寄っていかない）** |
| **パワー鬼** | 橙 | ×0.65 | ×2.5（範囲・半径 200cm） | **自分からは探しに行かない**（連打の音も気にしない）。代わりに**見えた壁を壊しに行く**。ただし**おとりの音には 1.6 倍の距離から寄っていく** |
| **慎重鬼** | 桃（ピンク） | ×1.15 | ×1.0（**1 個ずつ**） | **広い場所を手分けして見渡しながら調べる**（下）。囲まれた場所（空洞）は広い場所をほぼ見終わってから。**仲間が調べている・壊している建物には行かない** |
| **宝物鬼** | 金（橙＋王冠） | ×0.9 | ×0.4（範囲） | **お宝の周りをぐるぐる回る**（半径 2 マスを 2 周したら別のお宝へ。全部取られたら近場をうろうろ）。壁を壊すのも探すのも苦手（空洞は調べない・歩いて行ける所だけ回る）。**連打には鈍く（×0.3）、足音に敏感（×2.2）** |
| **探知鬼** | 紫＋アンテナ | ×0.9 | ×1.0（範囲） | 出てきたら**ランダムに決まった見張りの場所へ行き、そこから動かない**。首をゆっくり回して見張る（視界 1500cm・64 度）。**プレイヤーを見つけると、24m 以内の鬼を全員呼び寄せる**（5 秒ごと）。自分は追いかけない。音は聞かない |

#### 慎重鬼の探し方（M9 で見直し）

- 歩きながら**周り 4 マスの見通せるマス**（壁・家具の向こうは見えない）を「調べた」と記録し、**慎重鬼どうしで共有**する（60 秒覚えている）
- 舞台を**慎重鬼の数だけ南北に分けて担当**を決め、自分の担当の、まだ誰も見ていない広い場所から回る（担当の外は後回し）
- **細い道（両側が壁・家具）・行き止まりは後回し**。うろうろ中は細い道を通るのも嫌がる（遠回りでも広い所を通る）
- **壁に囲まれた場所（空洞）は、広い場所の見残しが 12% 以下になってから**調べに行く（壊して入る）。仲間が調べている・壊している・向かっている建物には行かない
- → **たくさん置いた壁・入り組んだ通路に弱い**が、何もない広い場所に隠れているとすぐ見つかる

#### 罠との相性

| 種類 | トリモチ | おとり |
|---|---|---|
| 標準鬼 | 普通（4 秒） | 普通（連打と同じ距離 × 1.2 から寄ってくる） |
| スピード鬼 | **弱い**（4 秒 × 1.5 = 6 秒動けない） | **強い**（だまされない） |
| パワー鬼 | **強い**（4 秒 × 0.4 = 1.6 秒で抜け出し、その後 3 秒の間に踏んだトリモチは**壊してしまう**） | **弱い**（1.6 倍の距離から寄ってくる） |
| 慎重鬼 | 普通 | 普通 |
| 宝物鬼 | 普通 | 弱め（×0.5 の距離からだけ寄る。足音の方に寄る） |
| 探知鬼 | 普通（見張りの場所で止まる） | 効かない（音を聞かない） |

数値は `Data/OniTypes.csv`（HearingScale / DecoyHearingScale / StunScale / bDisarmTraps）

- 画面左上の一覧に種類の名前と様子が出る（距離は出さない）。追いかけ始めた瞬間は頭の上に「！」
- **見た目**：Fab の「Cute Creature」（`Content/CuteCreature`）。種類ごとに色違い（標準=黒・スピード=青・パワー=橙・慎重=ピンク・宝物=橙＋金の王冠・探知=紫＋赤いランプのアンテナ。`OniTypes.csv` の MeshMaterial / MeshTint）、
  頭の上に種類の色の玉。体の高さ（190cm）に自動で合わせる。アニメーションは状態で切り替える（待機・走る・攻撃・見つけた・罠で動けない）。
  **アセットは Git に入れていない**（Fab のライセンスで公開リポジトリに置けないため）。無いパソコンでは円柱の見た目で動く

### 状態

```
Wander（うろうろ。行き先の選び方は種類ごと）
  ├─ 連打・足音を聞く ───▶ Investigate（音のした方へ。速さ 700）
  ├─ 探知鬼に呼ばれる ──▶ Investigate（プレイヤーが見つかった場所へ）
  │                          └─ 着いて見回しても何もない／8 秒たつ ─▶ Wander
  ├─ プレイヤーが見える ─▶ Chase（追いかける。速さ 840 ＝ プレイヤー 420 の 2 倍）
  │                          ├─ 2 秒見失う ─▶ Wander（また見つけたら追いかける。見えない間は最後に見えた場所へ向かう）
  │                          └─ 10 秒たつ ─▶ Wander（3 秒間は見えても追わない）
  └─ 空洞・見えた壁 ───▶ Inspect（調べに行く・壊して入る）
                             └─ 着いて見回す／20 秒たつ ─▶ Wander
進路に壁 ─▶ Attack（壊す）─▶ 元の状態へ
罠にかかる ─▶ Stunned（動けない。この間はプレイヤーに触れても捕まえられない）─▶ Wander（3 秒間は罠にかからない）
```

- **聴覚**：連打の音が聞こえる範囲（1200cm + 100cm/ステージ）にいると、その方向へ向かう。遠い音ほど場所が最大 3 マスずれる。
  ダッシュの音は 1.5 倍の距離まで届く。消音壁で囲まれた中の音は小さくなる。足音・ジャンプの音は別の距離（StepHearingScale）で聞く
- **足音**：鬼は歩くと歩幅ごとに「どたっ」と鳴る（その場所から聞こえる。20m 先で聞こえなくなる）。大きい鬼ほど低く重い
- **視覚**：懐中電灯の範囲（標準鬼は距離 900cm・正面 80 度）＋1.5m 以内は全方向。壁で遮られる。**見えたら追いかける（アウトにはしない）**
  - 視線は頭・体・足の 3 点で判定。ブロック 1 段（160cm）で体が全部隠れる
- **接触**：プレイヤーにぶつかったら（体が触れたら）発見＝アウト
- **攻撃**：進路上の壁を攻撃（溜め 0.8 秒）。攻撃力は 1 × 1.6^(ステージ-1) × 種類ごとの倍率。一番下の段に当たり、壊れると上の段が落ちてくる
  - 範囲攻撃（半径 160cm）は周りの壁もまとめて壊す。慎重鬼だけは目の前の 1 個だけ
- **移動**：独自のグリッド A*（8 方向、壁の角はすり抜けない）
  - **入り口から入る**：まず壁を「通れない」ものとして経路を探す。壁に隙間（入り口）があれば、遠回りでもそこから入る
  - **他に道が無いときだけ壁を壊す**：壁で完全に囲まれている（反対側へ行けない）・相手が壁の上にいるときだけ、壁を壊す経路を使う。
    壊す経路は「攻撃 1 回 ＝ 4 マスの回り道」として、壊す回数が少ない場所を選ぶ
  - **空洞は壊して調べる**：舞台のいちばん広い空間から歩いて行けない場所（例：角に斜めに壁を置いてできた三角形の中、壁で囲んだ部屋）は「空洞」。
    うろうろ中に空洞があると、種類ごとの確率でそこを調べに行き、壁を壊して入る
  - プレイヤーがジャンプしたり壁の上に乗ったりしても、真下でくるくる回らない（近すぎるときは向きだけ合わせて止まる）
  - **台の上にいるプレイヤーには飛び乗る**：家具や壁の上に立っているプレイヤーが見えたら、台のそばの歩けるマス（相手に一番近い所）まで行き、
    縁で真上に跳んで台の上に出てから相手へ向かう（`LeapMaxHeight` 280cm まで。部屋の壁 250cm・家具・壁 1 段に届く）。
    乗った台が隣の高い台につながっていれば、続けて飛び乗る。280cm より高い積んだ壁（2 段以上）は今まで通り下から壊す。
    ジャンプ中（空中）のプレイヤーには跳ばない

## レベルデザイン（ステージの並べ方）

プレイテストの結論：**スピードはトリモチに弱くおとりに強い、パワーはおとりに弱くトリモチに強い、慎重はたくさん置いた壁に弱いが効率よくプレイヤーを探しに来る。**
M9 で増えた鬼：**宝物鬼はお宝を守る（取りに行くなら足音を立てない・しのび足）、探知鬼は見張って仲間を呼ぶ（視線を家具や壁で切る）。**
これをもとに「1 つずつ覚える → 組み合わせで使い分けを問う」順に並べ、マップも 3 ステージごとに変える（`Data/Stages.csv` の Map 列）。
M10：全体に易しすぎたので、ステージ 3・6・8・10 に**標準鬼を 1 体ずつ足した**（難しくなりすぎないよう、少しだけ。最大 6 体は変えない）。

|---|---|---|---|
| 1 | 大広間 | 標準 | 家具の陰で、連打と時間で稼ぐ。1 体なので音を出しすぎなければ逃げ切れる |
| 2 | 大広間 | 標準・標準 | 壁で囲んで隠れる。入り口の向き・空洞は調べに来ること。歩くと足音が出ること |
| 3 | 大広間 | 標準・標準・**宝物** | **宝物鬼**：お宝の周りを回る（お宝は 4 個）。連打は気にしないが足音には敏感 → **しのび足**で取りに行く。壁を壊す力が弱いので壁で囲むと安全 |
| 4 | 書庫 | 標準・スピード | **スピード鬼**：速く、音に敏感。**トリモチ**で止める。おとりは効かない。本棚の通路で視線を切る |
| 5 | 書庫 | 標準・パワー | **パワー鬼**：見えた壁を壊しに来る。**おとり**で遠くへ引きつける。トリモチはすぐ壊される。ここから転生できる |

| 13〜 | 回廊 → 大広間 → … | スピード・パワー・慎重・慎重・宝物・探知 | 総合。表より後は数値だけ伸び、マップは 3 ステージごとに Maps.csv の順で回る |

- **転生の目安**：ステージ 5 から転生できるが、最初はステージ 7〜8（3〜4 pt）まで進めてからが効率がよい。
  - 最初に買うとよいもの：**煙幕ダッシュ**（見つかったときに煙で視線を切って逃げる・スピード鬼対策）、**壁の硬さ**（パワー鬼の一撃を耐える）
  - 消音壁を使うなら「消音壁の丈夫さ」、お宝を取りに行く遊び方なら「お宝の強化」
- 値段は買うほど上がる（壁 ×1.04〜1.08、消音壁・罠 ×1.5〜1.6）。安い壁はたくさん、罠と消音壁は少しずつ、が基本の形
- 壊れた壁・使った罠は購入パートの「まとめて補充」で買い直せる（高いものから）

## 館（マップ）

- 舞台は 24×24 マスの夜の館。マップごとに**家具（本棚・テーブル・暖炉・トランク…）と部屋の壁**が置いてあり、**壊せない・通れない**（鬼もプレイヤーも）。
  壁や罠は家具のマスには置けない。家具の陰は隠れ場所になる（低い家具＝テーブル・椅子は視線を通す）
- マップは `Data/Maps.csv`（名前・床と壁紙と明かりの色・間取りのファイル）と `Data/Maps/*.txt`（間取りを文字で描いたもの）。
  家具は `Data/Furniture.csv`（間取りの 1 文字 → メッシュ・高さ・明かり）。書き方は Data/README.md
- **ステージが進んでマップが変わると**（購入パートに入るとき）、置いていた壁と罠は**在庫に戻り**、前のマップの**設計図はとっておく**（そのマップに戻ったら在庫から自動で直る）
- 家具の見た目は Fab の「Stylized Library」（`Content/Stylized_Library`）。**Git には入れない**（鬼と同じ理由）。無いパソコンでは色の付いた箱で表示する
- 長い家具（"BBBB" の本棚の列）は同じメッシュを何個か並べ、家具の正面は部屋の空いている側へ向ける

| マップ | ステージ | 特徴 |
|---|---|---|
| 大広間 | 1〜3 | 家具は壁ぎわ。真ん中に大きなじゅうたん（歩ける）。広い |
| 書庫 | 4〜6 | 本棚の列で細い通路がたくさん |
| 客間 | 7〜9 | 部屋の壁で北と南に 2 部屋ずつ、真ん中は門まで続く廊下 |
| 物置 | 10〜12 | 小さな荷物がごちゃごちゃ。見通しが悪い |
| 回廊 | 13〜 | 真ん中の大部屋（入り口 4 つ）を廊下がぐるっと囲む |

### 雰囲気（夜の館・ポップで暗い）

- 月明かり（青白く弱い）と夜空、紫の霧。明るさの自動補正は EV 0.5〜1.5 に狭めて、暗い所は暗いまま
- 壁ぎわのランプ・暖炉・門のちょうちん（赤）が暖かい明かりの溜まりを作る。床は市松模様、壁紙はマップごとの色、色は鮮やかめ（彩度 ×1.25）、画面の四隅を暗く
- 鬼は懐中電灯を持ち、探知鬼は頭の上で赤いランプが光る

## 設置物

- **グリッドに沿って配置**（1 マス = 幅 100cm × **高さ 160cm（プレイヤーの背と同じ）**、24×24 マス、最大 3 段）
- プレイヤーはジャンプ（転生のお店で解放）でブロック 1 段に飛び乗れる
- 設置パートは真上から見下ろし、プレイヤーは表示しない。かくれんぼを始める場所（スタート位置）は床の青い印で示し、T でカーソルのマスへ動かす
- 照準の先にプレビュー（緑: 置ける / 赤: 置けない / 黄色の枠: 回収できる壁）。スタート位置・鬼の出入り口の前・家具のマスには置けない
- **設計図（配置の保存）**：プレイヤーが置いた・回収したときの状態を覚えておく。鬼に壊されても設計図は残る
- **自動修復**：設置パートの開始時に、壊れた壁を設計図どおりに**在庫から**作り直す
  - 購入パートで買い足した在庫も使える。在庫が足りない分は**赤い枠**で表示（手で置き直すか、次回在庫があれば直る）
  - プレイヤーが立っている（上に乗っている）列は、閉じ込めないよう直さない
  - 手で置いたり回収したりした列は、その状態が新しい設計図になる

| 壁 | 耐久 | 価格（1 個目 × 持っている数ごとの倍率） | 一撃で壊れるようになるステージ（転生なし・標準鬼） | 特徴 |
|---|---|---|---|---|
| 木の壁 | 1 | 10 × 1.04 | 1（常に一撃） | |
| 石の壁 | 4 | 120 × 1.06 | 4 | |
| 鉄の壁 | 16 | 1,500 × 1.08 | 7 | |
| **消音壁** | 3 | 300 × 1.5（罠と同じくらい上がる） | 3 | 囲まれた中の音を小さくする。**40 回音を消すと壊れる**（下） |

- **壁も買うほど高くなる**（持っている数 ＝ 在庫＋置いてある数。壊れた分は数えないので、買い直しの値段は上がらない）

- 鬼の攻撃力はステージごとに ×1.6 なので、後半はどの壁も一撃で壊れる。壁を硬くするには**転生のお店の「壁の硬さ」**を買う（「壁の補強」はやめた）

### 消音壁

- プレイヤーが**壁に囲まれた空洞の中にいるときだけ**効く（囲まれていなければ効かない）
- 空洞を囲んでいる壁（空洞のマスの周り 8 マスにある壁。積んだ列は一番下の段の種類）のうち、
  消音壁の割合だけ連打・ダッシュの音が小さくなる：**音の大きさ = 1 − (囲んでいる壁の NoiseDamping の平均)**。
  消音壁（0.8）だけで囲めば 80% 小さくなる（音の届く距離が 1/5）。半分なら 40%
- 床に出る音の輪も小さくなり、画面上部に「消音壁に囲まれている：音が〇% 小さい（消音壁はあと〇回で壊れる）」と出る
- おとりの音には効かない
- **音を消すたびに傷み、回数が尽きると壊れる**：囲んでいる消音壁（一番下の段）それぞれの「音を消せる回数」が、連打 1 回で 1、ダッシュ 1 回で 3 減る。
  基本は 40 回（`Walls.csv` の SoundHP）で、転生のお店の「消音壁の丈夫さ」で ×1.5 ずつ増える。壊れると囲みに穴が開く（設計図には残るので、在庫があれば次の設置パートで直る）。
  傷むほど色が暗くなる

### 罠

- 購入パートで買って在庫にし、設置パートで**壁の無い床のマス**に置く（1 マスに 1 個。壁とは同じマスに置けない）。
  当たり判定は無く、プレイヤーも鬼も上を通れる。右クリックで回収（残っていれば在庫に戻る）
- **価格は持っている数（在庫＋置いてある数）が増えるほど上がる**（トリモチ ×1.5・おとり ×1.6 ずつ）。置きすぎて鬼がずっと動けない、を防ぐ
- 使った罠は設計図に残り、次の設置パートで在庫があれば自動で置き直す（在庫が無ければ赤い枠。右クリックで設計図から消せる）

| 罠 | 価格 | 働き |
|---|---|---|
| トリモチ | 60 | 鬼が上を通ると **4 秒動けない**（頭の上で星が回る。種類で長さが変わる）。その間は触れても捕まらない。1 回で消える。抜け出した鬼は 3 秒間かからない（パワー鬼はこの間に踏んだトリモチを壊す） |
| おとり | 100 | 鬼が出てきてから **2.5 秒ごとに音**を出して鬼を呼ぶ（連打の 1.2 倍の距離まで届く。パワー鬼にはさらに 1.6 倍）。鬼が触れると壊れる。スピード鬼はだまされない |

## 視点

- **俯瞰**（購入・リザルト）：斜め上 60 度から自分を見下ろす。Q/E・マウスの左右・ホイールを押してドラッグで回転、ホイールでズーム
- **真上から**（設置）：舞台全体が入る高さから真下を見る。**プレイヤーは表示しない**（スタート位置は床の青い印）。
  WASD でカメラを画面の向きに動かす、Q/E・ホイールを押してドラッグ（左右）で回転、ホイールで高さを変える。
  **Z で斜めに傾ける・X で真上に戻す**（ホイールを押して上下にドラッグでも。真上 −90 度〜 −25 度）。積んだ壁の高さが見やすい。傾きは設置パートをまたいで覚えておく。
  カーソルを表示し、カーソルの指すマスにプレビューを出す
- **三人称**（かくれんぼ）：自分の背後の少し上から見る。マウスで回す、ホイールで距離を変える。WASD はカメラ基準
  - **置いたブロックはカメラがすり抜ける**ので、壁で囲んでも外から自分と周りが見える
  - 舞台の外周の壁にはカメラが当たって手前に寄る（舞台の外へ出ない）。体のすぐ後ろまで寄ったら自分の体は映さない
  - **鬼・お宝の方向表示はしない**（M9 でやめた）。代わりに**鬼の「どたどた」という足音・お宝の「キラキラ」という音**がその場所から聞こえる（左右の聞こえ方と大きさで、見えなくても「今ここにいそう」がわかる）。
    左上の一覧には鬼の様子（うろうろ / 音に気づいた / 追いかけてくる / お宝の周りを回っている / 見張っている…）だけを出す
  - 連打の手応えは画面に浮かぶ「+〇」で出す（カメラは揺らさない）
- 見た目の調整：夜の館（上の「雰囲気」）。モーションブラーなし
- 舞台の外周の上に見えない柵（プレイヤーとカメラは通さない。カーソルや鬼の視線は通す）

## 演出と音（M5）

音のファイルや Niagara のアセットが無くても動くよう、仮の演出と効果音はプログラムで作っている
（効果音は GameMode の SoundOverrides、BGM は MusicOverrides に音アセットを設定すると差し替わる）。

| きっかけ | 演出 | 音 |
|---|---|---|
| 連打 | 音の届く範囲に黄色い点線の輪が広がる・「+〇」 | ポッ |
| お宝を取る | 金色のきらきらが吹き上がる・輪・「お宝 +〇」 | 上がる和音 |
| 鬼に見つかる | 頭上の表示に「！」 | 「！」の 2 音 |
| 鬼の攻撃 | 足元から橙の衝撃波の輪 | — |
| 壁が傷つく / 壊れる | 壁の色の欠片が少し / 大きな破片が飛び散る | ゴッ / ガシャン（その場所から聞こえる） |
| トリモチ | 黄色い粒が飛ぶ・鬼の頭上で星が回る・「トリモチ にかかった！」 | ボヨン |
| おとり | 紫の輪が音の届く範囲まで広がる・人形が跳ねる / 壊れると破片 | ピピッ / 壊れる音 |
| 見つかった | 画面が赤く光る | 下がっていく音 |
| 逃げ切った | 画面が金色に光る・紙吹雪 | ファンファーレ |
| 開始前・残り 5 秒 | — | カウントダウン（3, 2, 1）・鬼が出てきた音・秒読み |

| 煙幕ダッシュ | 橙の輪が音の届く範囲まで広がる・足元に灰色の煙（1〜7 秒） | ダッ・シュッ＋ボフッ（煙幕） |
| 転生 | 画面が紫に光る・お知らせ | 上がっていく響き |
| プレイヤーの足音・ジャンプ | 控えめな青い輪 | トッ（小さく） / ぴょん |
| 鬼が歩く | — | **どたっ**（その場所から。大きい鬼ほど低い） |
| お宝 | 光る・回る | **キラキラ**（その場所から 1.6 秒ごと） |
| 探知鬼が仲間を呼ぶ | 紫の大きな輪・「探知鬼に見つかった！ 鬼が〇体集まってくる！」 | サイレン「ウーッ」 |

- 鬼・壁・罠・お宝の音は 3D（左右の聞こえ方と大きさで方向と距離がわかる）。鬼の足音とお宝のキラキラは「手がかりの音」として、近いほどはっきり大きく、20m 先で聞こえなくなる減り方。それ以外は画面全体で鳴る
- **BGM**（プログラムで作った曲をくり返す）：購入・設置・リザルトは「夜の館のおもちゃ箱」（Am−F−C−E、100 BPM、オルゴールとはねるベース）、
  かくれんぼは速くて少し怖い曲（Dm−B♭−Gm−A、126 BPM、刻むベースと太鼓・鐘）。パートが変わると 1 秒かけて切り替わる
- 音量はコンソールの `KakuVolume 0〜1`（全体）・`KakuMusicVolume 0〜1`（BGM）で変えられる
- 設置パートのグリッド線・プレビューの枠は開発用の描画機能を使っている（Shipping ビルドでは出ないので、配布前にメッシュに置き換える）

## インフレさせる要素（購入対象）

購入パートの並び（数字キー）: 1 連打コイン強化 / 2 時間コイン強化 / 3〜6 壁（木・石・鉄・消音） / 7〜8 罠

- 連打 1 回あたりのコイン（価格 15 × 1.7^Lv）
- 時間あたりのコイン（価格 25 × 1.7^Lv）
- 壁（上の表）
- 罠（上の表。持っている数が増えるほど高くなる）
- 壁と罠の行には「壊れた（使った）〇個（直すにはあと〇個）」を出す。在庫で直せるなら緑、足りなければ橙
- 商品の行・タブ・下のボタン（まとめて補充 / 転生する / 設置パートへ）はマウスでクリックできる（カーソルを乗せると明るくなる）。
  ボタンの位置はお店を切り替えても・転生できるようになっても動かない
- **まとめて補充（R）**：壊れた壁・使った罠を直すのに足りない分を、**値段の高いものから**買えるだけ買う。下に「あと〇個（〇コイン）」と出る

## 転生（プレステージ）

- **ステージ 5 から**、購入パートで **P を 2 回**（または「転生する」ボタンを 2 回）押すと転生できる（1 回目は確認。3 秒以内にもう一度）
- **転生ポイント = 今のステージ − 4**（ステージ 5 で 1、ステージ 8 で 4）をもらう
- 転生すると**コイン・ステージ・強化・壁と罠の在庫・置いてある壁と罠がなくなり**、**まず転生のお店が開く**（もらったポイントを使ってから、設置 → ステージ 1 のかくれんぼ）。
  **設計図（配置）は残る**ので、在庫を買い直せば設置パートで自動で直る
- 左上に「転生〇回・転生ポイント〇pt」を出す。数値は `Data/Prestige.csv`

### 転生のお店（永続強化）

購入パートの「転生のお店」タブ（Tab かクリック）で、転生ポイントを使って買う。**転生しても残る**。
価格 = 切り上げ(BaseCost × CostGrowth^レベル)、効果 = BaseValue × ValueGrowth^レベル（`Data/PrestigeUpgrades.csv`）

| 強化 | 最大 | 価格（pt） | 効果 |
|---|---|---|---|
| 壁の硬さ | なし | 1, 2, 3, 4, 6… | すべての壁の耐久 ×1.5^Lv（置いてある壁もすぐ硬くなる）。1 Lv で鬼の攻撃力の伸び（×1.6/ステージ）にほぼ 1 ステージぶん追いつく |
| お宝の強化 | なし | 1, 2, 3, 4, 6… | お宝の価値 ×1.5^Lv |
| 煙幕ダッシュ | 4 | 2, 4, 6, 9 | **Lv1 で煙幕ダッシュが使えるようになる**。煙が残る時間 1 → 3 → 5 → 7 秒（**足し算**：BaseValue + ValueGrowth × (Lv − 1)） |
| 煙幕の数 | 3 | 2, 4, 8 | 1 ラウンドに使える回数 1 → 2 → 3 → 4（**ここだけ足し算**：BaseValue + ValueGrowth × Lv） |
| ジャンプ | 1 | 2 | **ジャンプできるようになる** |
| 消音壁の丈夫さ | なし | 1, 2, 3, 4, 6… | 消音壁が音を消せる回数 ×1.5^Lv（40 → 60 → 90…。置いてある壁も） |

## パッケージ化（配布用の .exe）

UE エディタが無いパソコンでも遊べる形にする。

```powershell
cd C:\KakurenboIncremental
powershell -ExecutionPolicy Bypass -File Tools\Build.ps1     # 先にエディタ側をビルド
powershell -ExecutionPolicy Bypass -File Tools\Package.ps1   # パッケージ化（-Config Shipping も指定できる）
```

- 出来上がり: `Packaged/Windows/KakurenboIncremental.exe`。配るときは `Windows` フォルダごと渡す（`Packaged/` は Git に入れない）
- 初回はシェーダーの準備などで数十分かかる。2 回目からは速い
- エディタのメニュー（プラットフォーム → Windows → パッケージプロジェクト）ではなく、必ずスクリプトを使う
  - バランスの CSV（`Data/*.csv`）はアセットではないので自動では入らない。スクリプトが `KakurenboIncremental/Data` にコピーする
    （無いとプログラムの既定値で動き、CSV と違うバランスになる）
- 鬼の見た目（`Content/CuteCreature`）と家具（`Content/Stylized_Library`）はパスでしか参照していないので、DefaultGame.ini の `DirectoriesToAlwaysCook` で必ず入れている。
  そのパソコンに Fab アセットが無ければ、円柱の鬼・箱の家具のまま入る。間取り（`Data/Maps/*.txt`）も Data フォルダごとコピーされる
- **今は Development で作る**。Shipping では開発用の描画（設置パートの枠・グリッド線）が出ないので、メッシュに置き換えてから Shipping にする
- パッケージ版のセーブはエディタで遊んだセーブとは別の場所に保存される
