# かくれんぼインクリメンタル 設計書

## コンセプト

プレイヤーは**隠れる側**。鬼から逃げ切りながらコインを稼ぎ、ブロックや強化を買って
隠れ場所をインフレさせていく 3D インクリメンタルゲーム。

核となるジレンマ：**連打すれば稼げるが、音で鬼を呼び寄せる。**

## ゲームループ

```
[購入パート] → [設置パート] → [かくれんぼパート] → [リザルト] → [購入パート] …
```

| パート | プレイヤーの操作 | 内容 |
|---|---|---|
| 購入 | UI 操作のみ | コインで壁・罠・強化を購入する |
| 設置 | **移動できる** | 購入したブロックをグリッドに配置する（高低差あり） |
| かくれんぼ | 移動不可・連打のみ | 時間経過と連打でコインを得る。鬼が探しに来る |
| リザルト | — | 獲得コインを表示する。クリアなら次のステージを解放 |

## ルール

- かくれんぼパートは**制限時間制**
  - 制限時間まで逃げ切る → **大きな報酬** と **次のステージ**
  - 鬼に見つかる → **即アウト**。ペナルティはなく、それまでに稼いだコインを持ってリザルトへ
- 最初は何もない空間で棒立ちのまま、連打するしかない状態から始まる

## コイン収入

| 収入源 | 内容 |
|---|---|
| 時間収入 | 隠れている間、毎秒一定額を得る |
| 連打収入 | ボタン 1 回ごとに得る。**押すたびに音（Noise）が出る** |
| クリア報酬 | 逃げ切ったときにまとめて得る大きな報酬 |

## 鬼（AI）

- **聴覚**：連打の音を聞いて、その位置へ向かう
- **視覚**：プレイヤーが視界に入ったら発見（＝アウト）。壁で視線が遮られる
- **攻撃**：経路上の壁に**範囲攻撃**をする。基本は一撃で壊れる
- 移動は NavMesh。壁の設置や破壊のたびに経路を作り直す

## 設置物

- **グリッドに沿って配置**する（自由配置は作るのが難しいため採用しない）
- 積み上げによる高低差あり
- **壁**：耐久値あり。安い壁は一撃で壊れる。高い壁（強化）ほど耐えられる
  - **壊れた壁はなくなる**。買い直しが必要（＝コインの使い道が続く）
- **罠**：鬼を足止めする・遅くするなど（詳細は未定）

## インフレさせる要素（購入対象）

- 壁（耐久のランク）
- 連打 1 回あたりのコイン
- 時間あたりのコイン
- 罠
- 価格と効果の数値は DataTable（CSV）で管理し、指数カーブで調整する

## 未決定事項

- 罠の種類と効果
- 鬼の強化カーブ（ステージごとの速度、攻撃力、聴覚範囲）
- プレステージ（周回）要素の有無
- 連打の音量や聞こえる範囲を下げる強化を入れるかどうか

## マイルストーン

1. **M1 最小ループ**：何もない空間で棒立ちのまま連打してコインが増える。制限時間のカウントダウン、リザルト表示
2. **M2 鬼**：AI Perception（聴覚・視覚）で連打音に寄ってきて、発見したらアウト
3. **M3 購入と設置**：パートの切り替え、ショップ、グリッド配置、壁の耐久と破壊
4. **M4 インフレ**：DataTable による強化、ステージ進行、セーブとロード
5. **M5 罠・演出・バランス調整**
