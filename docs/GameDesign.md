# かくれんぼインクリメンタル 設計書

## コンセプト

プレイヤーは**隠れる側**。鬼から逃げ切りながらコインを稼ぎ、ブロックや強化を買って
隠れ場所をインフレさせていく 3D インクリメンタルゲーム。

核となるジレンマ：**連打すれば稼げるが、音で鬼を呼び寄せる。お宝を取りに行けば稼げるが、隠れ場所から出ることになる。**

## ゲームループ

```
（最初だけ）[かくれんぼ] → [リザルト] → [購入] → [設置] → [かくれんぼ] → …
```

| パート | 視点 | プレイヤーの操作 | 内容 |
|---|---|---|---|
| 購入 | 俯瞰 | 数字キーで購入 / Enter で次へ | コインで強化・壁・罠を購入する |
| 設置 | 俯瞰 | WASD・ジャンプで移動、カーソルでマスを指して置く・回収 | 壁と罠をグリッドに置く・回収する。**壊れた壁・使った罠は開始時に在庫から自動で直す** |
| かくれんぼ | **三人称** | WASD・ジャンプで移動、左クリック / F で連打、マウスでカメラ | 時間・連打・お宝でコインを得る。開始 3 秒後に鬼が出てくる（種類と数はステージごと） |
| リザルト | 俯瞰 | Enter で次へ | 獲得コイン・お宝・壊された壁・使った罠の数を表示。クリアなら次のステージへ |

## ルール

- かくれんぼパートは**制限時間制**（ステージ 1 は 30 秒、ステージごとに +5 秒）
  - 制限時間まで逃げ切る → **大きな報酬**（100 × 4^(ステージ-1)）と **次のステージ**
  - 鬼に**ぶつかる（体が触れる）と即アウト**。**ペナルティなし**で、稼いだコインを持ってリザルトへ
  - **鬼に見られただけではアウトにならない**（追いかけられる）
- かくれんぼ中も移動できる（隠れ場所から出てお宝を取りに行ける）
- 最初は何もない空間で、連打するしかない状態から始まる

## コイン収入

| 収入源 | 内容 |
|---|---|
| 時間収入 | 隠れている間、毎秒一定額を得る（1 × 1.5^Lv） |
| 連打収入 | 1 回ごとに得る（1 × 1.5^Lv）。**押すたびに音が出る** |
| お宝 | 毎ラウンド **3 個**がランダムな空きマスに出現。1 個 = 逃げ切り報酬 × 0.3。プレイヤー・他のお宝から 4 マス以上離れた場所。取れなかった分はラウンド終了で消える |
| クリア報酬 | 逃げ切ったときにまとめて得る大きな報酬 |

## 鬼（AI）— 4 種類

- ステージごとに出てくる鬼の種類と数が決まっている。`Data/Stages.csv` の OniTypes 列。
  新しい種類を 1 つずつ覚えられるよう、少しずつ登場させる：

| ステージ | 鬼 |
|---|---|
| 1 | 標準・標準 |
| 2 | 標準・スピード |
| 3 | 標準・パワー |
| 4 | スピード・慎重・慎重 |
| 5 | 標準・スピード・パワー |
| 6 | スピード・パワー・慎重・慎重 |
| 7 | 標準・スピード・パワー・慎重 |
| 8 | 標準・スピード・パワー・慎重・慎重 |
| 9 | 標準・スピード・パワー・パワー・慎重・慎重 |
| 10〜 | 標準・スピード・スピード・パワー・慎重・慎重 |

- 出現位置：プレイヤーからも鬼どうしでも、なるべく遠い空きマス
- 速さ：うろうろ 420 / 調べる 700 / 追いかける 840（標準鬼。プレイヤー 420 の 2 倍。見つかったら走って逃げ切るのは難しく、壁の陰で見失わせる）× 種類ごとの倍率 ＋ステージごとの加算

### 種類（パックマンの鬼のように性格が違う）

| 種類 | 色 | 速さ | 壁を壊す力 | 探し方 |
|---|---|---|---|---|
| **標準鬼** | 赤 | ×1.0 | ×1.0（範囲） | 近くをうろうろ。音に寄ってくる。空洞は 50% で調べる |
| **スピード鬼** | 水色 | ×1.25 | ×0.5（範囲） | **大雑把に全体を見て回る**：舞台を 4×4 マスの区画に分けて、しばらく行っていない区画へ走る。視界が広い（1300cm・110 度）。空洞は調べない |
| **パワー鬼** | 橙 | ×0.65 | ×2.5（範囲・半径 200cm） | **自分からは探しに行かない**（音も気にしない）。代わりに**見えた壁を壊しに行く** |
| **慎重鬼** | 桃 | ×1.15 | ×1.0（**1 個ずつ**） | **近くの調べていないマスから順に隅々まで調べる**ので、全体を見るのは遅い。**慎重鬼どうしで調べたマスを共有**（45 秒覚えている）し、仲間が調べた場所・仲間が向かっている場所の近くには行かない。空洞は必ず調べる |

- 頭上の表示と画面左上の一覧に種類の名前と色が出る。追いかけ始めた瞬間は「！」が付く

### 状態

```
Wander（うろうろ。行き先の選び方は種類ごと）
  ├─ 連打の音を聞く ─────▶ Investigate（音のした方へ。速さ 700）
  │                          └─ 着いて見回しても何もない／8 秒たつ ─▶ Wander
  ├─ プレイヤーが見える ─▶ Chase（追いかける。速さ 840 ＝ プレイヤー 420 の 2 倍）
  │                          ├─ 2 秒見失う ─▶ Wander（また見つけたら追いかける。見えない間は最後に見えた場所へ向かう）
  │                          └─ 10 秒たつ ─▶ Wander（3 秒間は見えても追わない）
  └─ 空洞・見えた壁 ───▶ Inspect（調べに行く・壊して入る）
                             └─ 着いて見回す／20 秒たつ ─▶ Wander
進路に壁 ─▶ Attack（壊す）─▶ 元の状態へ
罠にかかる ─▶ Stunned（動けない。この間はプレイヤーに触れても捕まえられない）─▶ Wander（3 秒間は罠にかからない）
```

- **聴覚**：連打の音が聞こえる範囲（1200cm + 100cm/ステージ）にいると、その方向へ向かう。遠い音ほど場所が最大 3 マスずれる
- **視覚**：懐中電灯の範囲（標準鬼は距離 900cm・正面 80 度）＋1.5m 以内は全方向。壁で遮られる。**見えたら追いかける（アウトにはしない）**
  - 視線は頭・体・足の 3 点で判定。ブロック 1 段（160cm）で体が全部隠れる
- **接触**：プレイヤーにぶつかったら（体が触れたら）発見＝アウト
- **攻撃**：進路上の壁を攻撃（溜め 0.8 秒）。攻撃力は 1 × 1.6^(ステージ-1) × 種類ごとの倍率。一番下の段に当たり、壊れると上の段が落ちてくる
  - 範囲攻撃（半径 160cm）は周りの壁もまとめて壊す。慎重鬼だけは目の前の 1 個だけ
- **移動**：独自のグリッド A*（8 方向、壁の角はすり抜けない）
  - **入り口から入る**：まず壁を「通れない」ものとして経路を探す。壁に隙間（入り口）があれば、遠回りでもそこから入る
  - **他に道が無いときだけ壁を壊す**：壁で完全に囲まれている（反対側へ行けない）・相手が壁の上にいるときだけ、壁を壊す経路を使う。
    壊す経路は「攻撃 1 回 ＝ 4 マスの回り道」として、壊す回数が少ない場所を選ぶ
  - **空洞は壊して調べる**：舞台のいちばん広い空間から歩いて行けない場所（例：角に斜めに壁を置いてできた三角形の中、壁で囲んだ部屋）は「空洞」。
    うろうろ中に空洞があると、種類ごとの確率でそこを調べに行き、壁を壊して入る
  - プレイヤーがジャンプしたり壁の上に乗ったりしても、真下でくるくる回らない（近すぎるときは向きだけ合わせて止まる）

## 設置物

- **グリッドに沿って配置**（1 マス = 幅 100cm × **高さ 160cm（プレイヤーの背と同じ）**、24×24 マス、最大 3 段）
- プレイヤーはジャンプでブロック 1 段に飛び乗れる
- 照準の先にプレビュー（緑: 置ける / 赤: 置けない / 黄色の枠: 回収できる壁）。自分と重なる場所には置けない
- **設計図（配置の保存）**：プレイヤーが置いた・回収したときの状態を覚えておく。鬼に壊されても設計図は残る
- **自動修復**：設置パートの開始時に、壊れた壁を設計図どおりに**在庫から**作り直す
  - 購入パートで買い足した在庫も使える。在庫が足りない分は**赤い枠**で表示（手で置き直すか、次回在庫があれば直る）
  - プレイヤーが立っている（上に乗っている）列は、閉じ込めないよう直さない
  - 手で置いたり回収したりした列は、その状態が新しい設計図になる

| 壁 | 耐久 | 価格 | 一撃で壊れるようになるステージ（補強なし・標準鬼） |
|---|---|---|---|
| 木の壁 | 1 | 10 | 1（常に一撃） |
| 石の壁 | 4 | 120 | 4 |
| 鉄の壁 | 16 | 1,500 | 7 |

- **壁の補強**（強化）：すべての壁の耐久 × 1.5^Lv（価格 200 × 3^Lv）。置いてある壁にもすぐ効く。
  鬼の攻撃力はステージごとに ×1.6 なので、補強しないと後半はどの壁も一撃で壊れる

### 罠

- 購入パートで買って在庫にし、設置パートで**壁の無い床のマス**に置く（1 マスに 1 個。壁とは同じマスに置けない）。
  当たり判定は無く、プレイヤーも鬼も上を通れる。右クリックで回収（残っていれば在庫に戻る）
- **価格は持っている数（在庫＋置いてある数）が増えるほど上がる**（×1.3〜1.35 ずつ）。置きすぎて鬼がずっと動けない、を防ぐ
- 使った罠は設計図に残り、次の設置パートで在庫があれば自動で置き直す（在庫が無ければ赤い枠。右クリックで設計図から消せる）

| 罠 | 価格 | 働き |
|---|---|---|
| トリモチ | 60 | 鬼が上を通ると **4 秒動けない**（頭の上で星が回る）。その間は触れても捕まらない。1 回で消える。抜け出した鬼は 3 秒間かからない |
| おとり | 100 | 鬼が出てきてから **2.5 秒ごとに音**を出して鬼を呼ぶ（連打の 1.2 倍の距離まで届く）。鬼が触れると壊れる。パワー鬼は音を気にしないので効かない |

## 視点

- **俯瞰**（購入・設置・リザルト）：斜め上 60 度から見下ろす。Q/E・ホイールを押してドラッグ（購入とリザルトではマウスの左右でも）で回転、ホイールでズーム。
  設置パートではカーソルを表示し、カーソルの指すマスにプレビューを出す。WASD は画面基準
- **三人称**（かくれんぼ）：自分の背後の少し上から見る。マウスで回す、ホイールで距離を変える。WASD はカメラ基準
  - **置いたブロックはカメラがすり抜ける**ので、壁で囲んでも外から自分と周りが見える
  - 舞台の外周の壁にはカメラが当たって手前に寄る（舞台の外へ出ない）。体のすぐ後ろまで寄ったら自分の体は映さない
  - **鬼・お宝の方向表示**：画面内なら頭上に ▼ と距離（壁越しでも表示）、画面外なら画面の縁に矢印。鬼の色は状態（白: うろうろ / 橙: 音に気づいた・壁を壊している / 赤: 追いかけてくる）
  - 連打の手応えは画面に浮かぶ「+〇」で出す（カメラは揺らさない）
- 見た目の調整：暗い場所を無理に明るくしない（明るさの自動補正の下限 EV 0）、モーションブラーなし
- 舞台の外周の上に見えない柵（プレイヤーとカメラは通さない。カーソルや鬼の視線は通す）

## 演出と音（M5）

音のファイルや Niagara のアセットが無くても動くよう、仮の演出と効果音はプログラムで作っている
（音は GameMode の SoundOverrides に音アセットを設定すると差し替わる）。

| きっかけ | 演出 | 音 |
|---|---|---|
| 連打 | 音の届く範囲に黄色い点線の輪が広がる・「+〇」 | ポッ |
| お宝を取る | 金色のきらきらが吹き上がる・輪・「お宝 +〇」 | 上がる和音 |
| 鬼に見つかる | 頭上の表示に「！」 | 「！」の 2 音 |
| 鬼の攻撃 | 足元から橙の衝撃波の輪 | — |
| 壁が傷つく / 壊れる | 壁の色の欠片が少し / 大きな破片が飛び散る | ゴッ / ガシャン（その場所から聞こえる） |
| トリモチ | 黄色い粒が飛ぶ・鬼の頭上で星が回る・「トリモチ にかかった！」 | ボヨン |
| おとり | 紫の輪が音の届く範囲まで広がる・人形が跳ねる / 壊れると破片 | ピピッ / 壊れる音 |
| 見つかった | 画面が赤く光る | 下がっていく音 |
| 逃げ切った | 画面が金色に光る・紙吹雪 | ファンファーレ |
| 開始前・残り 5 秒 | — | カウントダウン（3, 2, 1）・鬼が出てきた音・秒読み |
| 購入・設置 | — | チャリン（買えないときはブー）・置く音・回収の音 |

- 鬼・壁・罠の音は 3D（左右の聞こえ方と大きさで方向と距離がわかる）。それ以外は画面全体で鳴る
- 音量はコンソールの `KakuVolume 0〜1` で変えられる
- 設置パートのグリッド線・プレビューの枠は開発用の描画機能を使っている（Shipping ビルドでは出ないので、配布前にメッシュに置き換える）

## インフレさせる要素（購入対象）

購入パートの並び（数字キー）: 1 連打コイン強化 / 2 時間コイン強化 / 3 壁の補強 / 4〜6 壁 / 7〜8 罠

- 連打 1 回あたりのコイン（価格 15 × 1.7^Lv）
- 時間あたりのコイン（価格 25 × 1.7^Lv）
- 壁の補強（価格 200 × 3^Lv、耐久 × 1.5^Lv）
- 壁（上の表）
- 罠（上の表。持っている数が増えるほど高くなる）
- 数値は `KakurenboIncremental/Data/*.csv`（Stages / Upgrades / Walls / OniTypes / Traps）で調整する。書き方は Data/README.md

## セーブ

- 保存するもの：コイン・ステージ・強化レベル（壁の補強を含む）・壁と罠の在庫・壁と罠の配置（設計図と残っているもの）・プレイヤーの位置
- かくれんぼ以外のパートに入るたび、かくれんぼの開始時に自動で保存（`Saved/SaveGames/Kakurenbo.sav`）
- 起動時にセーブがあれば設置パートから再開。コンソールで `KakuResetSave` を実行すると最初からやり直す
